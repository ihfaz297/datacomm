0. The whole topic in six sentences

  1. Feed the complex sinusoid e^{j\omega n} into an LTI system and the same sinusoid comes out, multiplied by one complex number, H(e^{j\omega}).
  2. That number is H(e^{j\omega}) = \sum_k h[k]\,e^{-j\omega k}, the DTFT of the impulse response. It is called the frequency response.
  3. In polar form, H(e^{j\omega}) = |H(e^{j\omega})|\,e^{j\theta(\omega)}. The magnitude is the gain at that frequency and \theta(\omega) is the phase shift.
  4. So a cosine goes in and a cosine comes out, at the same frequency, scaled by |H| and shifted by \theta.
  5. If the input is switched on at n = 0 instead of running forever, you get that steady-state cosine plus a transient, which dies away if the system is stable.
  6. A filter is just an |H| chosen on purpose: close to 1 at the frequencies you want to keep, close to 0 at the ones you want to remove.

1. Why e^{j\omega n} is special: the eigenfunction proof

Syllabus 4.8 and 4.8.1. The most likely "prove that" part of the question.

Start with the idea. Convolution adds up delayed copies of the input, and for most inputs that changes the shape. A complex exponential is different: a delayed copy of it, e^{j\omega(n-k)}, is the original multiplied by a constant, e^{-j\omega k}. So when convolution adds up delayed copies, it is really adding constants times the same signal, and the shape survives.

In the exam, write:

For an LTI system with impulse response h[n], the output is the convolution sum

y[n] = \sum_{k=-\infty}^{\infty} h[k]\,x[n-k].

Let x[n] = e^{j\omega n} for all n. Then

\begin{aligned} y[n] &= \sum_{k=-\infty}^{\infty} h[k]\,e^{j\omega(n-k)} = e^{j\omega n}\underbrace{\sum_{k=-\infty}^{\infty} h[k]\,e^{-j\omega k}}_{H(e^{j\omega})} \\[4pt] &= H(e^{j\omega})\,e^{j\omega n}. \end{aligned}

The sum depends on \omega but not on n, so for a given frequency it is a constant. The output is the input multiplied by a constant. Therefore e^{j\omega n} is an eigenfunction of every LTI system, and H(e^{j\omega}) is the corresponding eigenvalue. H(e^{j\omega}) is called the frequency response.

Your note draws an arrow from e^{j\omega n} to the word "eigenfunction" and from H(e^{j\omega}) to "eigenvalue". Do the same; that labelling is worth a mark.

A small example from the note. Suppose H(e^{j\omega}) = 2e^{-j\pi/4} at some frequency. Then

x[n] = e^{j\omega n} \quad\longmapsto\quad y[n] = 2e^{-j\pi/4}\,e^{j\omega n} = 2e^{j(\omega n - \pi/4)}.

The amplitude doubled, the phase moved back by \pi/4, and the frequency \omega did not change. An LTI system can never create a new frequency.

1a. Exercise 4.54

(i) Show that z^n is an eigenfunction, for any complex constant z.

y[n] = \sum_k h[k]\,z^{n-k} = z^n\sum_k h[k]\,z^{-k} = H(z)\,z^n.

The sum does not depend on n, so z^n is an eigenfunction and its eigenvalue is H(z), the z-transform of h[n].

(ii) Is v[n] = z^n u[n] an eigenfunction?

y[n] = \sum_k h[k]\,z^{n-k}\,u[n-k] = z^n\sum_k h[k]\,z^{-k}\,u[n-k].

This time the sum still contains u[n-k], so it does depend on n. It is not a constant, so z^n u[n] is not an eigenfunction.

The reason is worth remembering. Switching the input on at n = 0 is exactly what creates a transient (Section 6). The output needs a few samples to settle into H(z)\,z^n.

2. Magnitude, phase, decibels and symmetry

Syllabus 4.8.1 and 4.8.2.

H(e^{j\omega}) is a complex number at each frequency, so it can be written two ways:

H(e^{j\omega}) = H_R(\omega) + jH_I(\omega) = |H(e^{j\omega})|\,e^{j\theta(\omega)}.
Name Formula What it tells you
Magnitude response \lvert H(e^{j\omega})\rvert = \sqrt{H_R^2(\omega) + H_I^2(\omega)} how much that frequency is amplified or shrunk
Phase response \theta(\omega) = \tan^{-1}\big(H_I(\omega)/H_R(\omega)\big) how far that frequency is shifted (mind the quadrant)
Gain in dB \mathcal{G}(\omega) = 20\log_{10}\lvert H(e^{j\omega})\rvert positive amplifies, zero leaves alone, negative attenuates
Periodicity H(e^{j(\omega + 2\pi)}) = H(e^{j\omega}) you only ever need -\pi \le \omega \le \pi
Real h[n] H(e^{-j\omega}) = H^*(e^{j\omega}) magnitude is even, phase is odd, so 0 \le \omega \le \pi is enough
Convolution y = h * x \iff Y(e^{j\omega}) = H(e^{j\omega})\,X(e^{j\omega}) so H = Y/X

Watch the quadrant. A calculator's \tan^{-1} only returns angles between -90^\circ and +90^\circ. If the real part H_R is negative, the true angle is in the left half of the plane, so add or subtract 180^\circ. For example, H = -18 at \omega = \pi has phase \pm 180^\circ, not 0.

3. Sinusoid in, sinusoid out: the steady-state response

Syllabus 4.8.2. Sir has asked this derivation before (note p.19).

Question. Develop an expression for the steady-state response of an LTI discrete-time system with real impulse response h[n] to the input x[n] = A\cos(\omega_0 n + \phi), in terms of H(e^{j\omega}).

The plan: a cosine is two complex exponentials (Euler), each exponential is an eigenfunction (Section 1), so each one is simply multiplied by H at its own frequency. Then put them back together.

In the exam, write:

By Euler's formula,

x[n] = A\cos(\omega_0 n + \phi) = \frac{A}{2}\,e^{j\phi}e^{j\omega_0 n} + \frac{A}{2}\,e^{-j\phi}e^{-j\omega_0 n}.

Each exponential is an eigenfunction, so by linearity

y[n] = \frac{A}{2}\,e^{j\phi}H(e^{j\omega_0})\,e^{j\omega_0 n} + \frac{A}{2}\,e^{-j\phi}H(e^{-j\omega_0})\,e^{-j\omega_0 n}.

Because h[n] is real, H(e^{-j\omega_0}) = H^*(e^{j\omega_0}). Write H(e^{j\omega_0}) = |H(e^{j\omega_0})|\,e^{j\theta(\omega_0)}, so that H(e^{-j\omega_0}) = |H(e^{j\omega_0})|\,e^{-j\theta(\omega_0)}. Then

\begin{aligned} y[n] &= \frac{A}{2}\,|H(e^{j\omega_0})|\Big[e^{j(\omega_0 n + \phi + \theta(\omega_0))} + e^{-j(\omega_0 n + \phi + \theta(\omega_0))}\Big] \\[4pt] &= \boxed{A\,|H(e^{j\omega_0})|\cos\big(\omega_0 n + \phi + \theta(\omega_0)\big)} \end{aligned}

The output is a cosine at the same frequency. Its amplitude is multiplied by |H(e^{j\omega_0})| and its phase is shifted by \theta(\omega_0).

H(e^{j\omega}) = \sum_{n=0}^{3} h[n]\,e^{-j\omega n} = -3 + 6e^{-j\omega} - 5e^{-j2\omega} + 4e^{-j3\omega},

and the output is

3b. Mitra 4.68: h[n] = (0.4)^n u[n] and x[n] = \sin(\pi n/4)\,u[n]. Find y_{ss}[n].

First the frequency response. It is a geometric series, and it converges because |0.4| < 1:

H(e^{j\omega}) = \sum_{n=0}^{\infty}\big(0.4e^{-j\omega}\big)^n = \frac{1}{1 - 0.4e^{-j\omega}}.

Now evaluate it at the input frequency \omega = \pi/4, where e^{-j\pi/4} = \tfrac{1}{\sqrt2} - \tfrac{j}{\sqrt2} \approx 0.7071 - 0.7071j:

\begin{aligned} 1 - 0.4e^{-j\pi/4} &= 1 - 0.4(0.7071 - 0.7071j) = 0.71716 + 0.28284j, \\[4pt] H(e^{j\pi/4}) &= \frac{1}{0.71716 + 0.28284j} = 1.20669 - 0.47591j. \end{aligned}

So the gain and the phase are

|H(e^{j\pi/4})| = 1.29715, \qquad \theta(\pi/4) = \tan^{-1}\frac{-0.47591}{1.20669} = -21.52^\circ = -0.3757 \text{ rad}.

The input is a sine, so the output is a sine:

\boxed{y_{ss}[n] = 1.29715\,\sin\!\left(\frac{\pi n}{4} - 0.3757\right)}

Two things to notice. At -\pi/4 you get the conjugate, 1.20669 + 0.47591j, with the same magnitude and phase +21.52^\circ; that is the symmetry from Section 2. And if you simulate the true output, by n = 50 it matches this formula to 15 digits, so the transient really has died out.

4. FIR frequency responses and the cascade exercises

For an FIR filter the convolution sum is finite, y[n] = \sum_{k=N_1}^{N_2} h[k]\,x[n-k], so the frequency response is a finite sum with no convergence worries:

H(e^{j\omega}) = \sum_{k=N_1}^{N_2} h[k]\,e^{-j\omega k}.

These DTFT pairs from note p.16 are enough to do every exercise below almost in your head:

x[n] X(e^{j\omega})
\delta[n] 1
\delta[n-k] e^{-j\omega k}
a^n u[n], with \lvert a\rvert < 1 \dfrac{1}{1 - ae^{-j\omega}}
c\,x[n] c\,X(e^{j\omega})
x[n - n_0] e^{-j\omega n_0}X(e^{j\omega})

4a. Mitra 4.56: h[n] = \delta[n] - \alpha\,\delta[n-R]. Find G(e^{j\omega}) for g[n] = h[n] * h[n] * h[n].

Each copy of h has H(e^{j\omega}) = 1 - \alpha e^{-j\omega R}. Convolution in time is multiplication in frequency, so three convolutions give a cube. Expand it with (1 - u)^3 = 1 - 3u + 3u^2 - u^3, taking u = \alpha e^{-j\omega R}:

G(e^{j\omega}) = \big(1 - \alpha e^{-j\omega R}\big)^3 = 1 - 3\alpha e^{-j\omega R} + 3\alpha^2 e^{-j2\omega R} - \alpha^3 e^{-j3\omega R}.

Your note has a slip here. It writes 1 - 3e^{-j\omega R} + 3e^{-j2\omega R} + e^{-j3\omega R}, which drops every \alpha and gets the last sign wrong. Use the version above.

4b. Mitra 4.64: when is the cascade all-pass?

The cascade is h_1[n] = \alpha\,\delta[n] + \delta[n-1] followed by h_2[n] = \beta^n u[n] with |\beta| < 1. For which \alpha and \beta is |H(e^{j\omega})| = 1 at every frequency?

Multiply the two frequency responses:

H(e^{j\omega}) = H_1(e^{j\omega})\,H_2(e^{j\omega}) = \frac{\alpha + e^{-j\omega}}{1 - \beta e^{-j\omega}}.

|H| = 1 means the top and the bottom have the same magnitude. Square both sides, using |z|^2 = z\,z^*:

\begin{aligned} \big|\alpha + e^{-j\omega}\big|^2 &= \big|1 - \beta e^{-j\omega}\big|^2 \\[2pt] \alpha^2 + 2\alpha\cos\omega + 1 &= 1 - 2\beta\cos\omega + \beta^2. \end{aligned}

This has to hold at every \omega, so the constant terms must match and the \cos\omega terms must match:

\alpha^2 = \beta^2 \quad\text{and}\quad 2\alpha = -2\beta \qquad\Longrightarrow\qquad \boxed{\alpha = -\beta, \quad |\beta| < 1}

The second condition already implies the first. A filter whose magnitude is 1 at every frequency is called an all-pass filter: it changes only the phase. With \beta = 0.6 and \alpha = -0.6, |H| = 1.000 at every \omega tested.

4c. Mitra 4.76: show that this third-order system is all-pass

y[n] = d_3x[n] + d_2x[n-1] + d_1x[n-2] + x[n-3] - d_1y[n-1] - d_2y[n-2] - d_3y[n-3]

Take the DTFT of both sides and solve for Y/X:

H(e^{j\omega}) = \frac{d_3 + d_2e^{-j\omega} + d_1e^{-j2\omega} + e^{-j3\omega}}{1 + d_1e^{-j\omega} + d_2e^{-j2\omega} + d_3e^{-j3\omega}}.

Call the denominator D(e^{j\omega}). The numerator has the same coefficients in reverse order. Factor e^{-j3\omega} out of it:

d_3 + d_2e^{-j\omega} + d_1e^{-j2\omega} + e^{-j3\omega} = e^{-j3\omega}\big(1 + d_1e^{j\omega} + d_2e^{j2\omega} + d_3e^{j3\omega}\big) = e^{-j3\omega}\,D^*(e^{j\omega}),

because the d_i are real. Therefore

|H(e^{j\omega})| = \frac{|e^{-j3\omega}|\,|D^*(e^{j\omega})|}{|D(e^{j\omega})|} = \frac{1\cdot|D(e^{j\omega})|}{|D(e^{j\omega})|} = 1 \quad\text{for every } \omega. \qquad\blacksquare

A pattern worth spotting: if the numerator's coefficients are the denominator's coefficients read backwards, the filter is all-pass.

4d. Mitra 4.61: when is this non-causal FIR zero-phase?

h[n] = a_1\delta[n-3] + a_2\delta[n-2] + a_3\delta[n-1] + a_4\delta[n] + a_5\delta[n+1] + a_6\delta[n+2]

"Zero phase" means H(e^{j\omega}) is real at every frequency. For a real h[n] that happens exactly when h[n] is even, h[n] = h[-n], because then each pair of terms gives h[k]\big(e^{-j\omega k} + e^{j\omega k}\big) = 2h[k]\cos\omega k, which is real.

So match the samples in pairs:

  • n = \pm 3: h[3] = a_1 but h[-3] = 0, so a_1 = 0.
  • n = \pm 2: a_2 = a_6.
  • n = \pm 1: a_3 = a_5.
  • n = 0: a_4 can be any real number.

4e. Mitra 4.63: for which k is the frequency response real?

y[n] = a_1x[n+k] + a_2x[n+k-1] + a_3x[n+k-2] + a_2x[n+k-3] + a_1x[n+k-4]

Every term carries a factor e^{j\omega k}, so pull it out:

H(e^{j\omega}) = e^{j\omega k}\big(a_1 + a_2e^{-j\omega} + a_3e^{-j2\omega} + a_2e^{-j3\omega} + a_1e^{-j4\omega}\big).

The coefficients inside are symmetric about the middle one, so factor out e^{-j2\omega} and pair the terms using e^{j\theta} + e^{-j\theta} = 2\cos\theta:

H(e^{j\omega}) = e^{j\omega(k-2)}\big[a_3 + 2a_2\cos\omega + 2a_1\cos 2\omega\big].

The bracket is real. So H is real at every \omega exactly when e^{j\omega(k-2)} = 1, which means \boxed{k = 2}.

4f. Mitra 4.57: g[n] = \alpha^n for 0 \le n \le M-1. Find G(e^{j\omega}) and scale it to unity DC gain.

It is a finite geometric series, \sum_{n=0}^{M-1} r^n = \dfrac{1 - r^M}{1 - r}, with r = \alpha e^{-j\omega}:

G(e^{j\omega}) = \sum_{n=0}^{M-1}\big(\alpha e^{-j\omega}\big)^n = \frac{1 - \alpha^M e^{-j\omega M}}{1 - \alpha e^{-j\omega}}.

"DC gain" means the value at \omega = 0:

G(e^{j0}) = \frac{1 - \alpha^M}{1 - \alpha}.

To make that equal to 1, multiply g[n] by its reciprocal:

\boxed{g'[n] = \frac{1 - \alpha}{1 - \alpha^M}\,\alpha^n, \qquad 0 \le n \le M-1}

Check: with \alpha = 0.5 and M = 4, the DC value is 1 + 0.5 + 0.25 + 0.125 = 1.875, and (1 - 0.0625)/0.5 = 1.875 too.

5. The moving-average filter

Syllabus 4.8.4. If it is asked, it is a full derivation, and it is close to free marks once you have practised it.

Past paper 5b: "Compute the magnitude and phase response of a 5-point moving average filter."

The picture first. A moving average replaces each sample by the average of the last M samples. Slow changes survive the averaging; fast wiggles cancel themselves out. So expect a low-pass filter before writing a single line.

In the exam, write:

The M-point moving-average filter is

y[n] = \frac{1}{M}\sum_{\ell=0}^{M-1} x[n-\ell], \qquad\text{so}\qquad h[n] = \begin{cases} 1/M, & 0 \le n \le M-1, \\ 0, & \text{otherwise.} \end{cases}

The impulse response has finite length, so this is an FIR filter. Its frequency response is a finite geometric series:

H(e^{j\omega}) = \frac{1}{M}\sum_{n=0}^{M-1} e^{-j\omega n} = \frac{1}{M}\cdot\frac{1 - e^{-j\omega M}}{1 - e^{-j\omega}}.

Factor e^{-j\omega M/2} out of the numerator and e^{-j\omega/2} out of the denominator, so that each bracket becomes a sine:

\begin{aligned} H(e^{j\omega}) &= \frac{1}{M}\cdot\frac{e^{-j\omega M/2}\big(e^{j\omega M/2} - e^{-j\omega M/2}\big)}{e^{-j\omega/2}\big(e^{j\omega/2} - e^{-j\omega/2}\big)} = \frac{1}{M}\cdot e^{-j(M-1)\omega/2}\cdot\frac{2j\sin(M\omega/2)}{2j\sin(\omega/2)} \\[6pt] &= \boxed{\frac{1}{M}\,\frac{\sin(M\omega/2)}{\sin(\omega/2)}\;e^{-j(M-1)\omega/2}} \end{aligned}

Reading off the magnitude and the phase:

|H(e^{j\omega})| = \left|\frac{1}{M}\,\frac{\sin(M\omega/2)}{\sin(\omega/2)}\right|, \qquad \theta(\omega) = -\frac{(M-1)\,\omega}{2} + \pi\sum_{k=1}^{\lfloor M/2\rfloor}\mu\!\left(\omega - \frac{2\pi k}{M}\right), \quad 0 \le \omega \le \pi,

where \mu(\cdot) is the unit step function (Mitra's notation).

Why does the phase have those +\pi jumps? The ratio \sin(M\omega/2)/\sin(\omega/2) is real, but it turns negative after each zero at \omega = 2\pi k/M. A negative real number is its magnitude times e^{j\pi}, so the phase picks up an extra \pi at each zero. Between the jumps the phase is a straight line of slope -(M-1)/2, and a straight-line phase means a pure delay of (M-1)/2 samples.

With M = 5:

|H(e^{j\omega})| = \left|\frac{\sin(5\omega/2)}{5\sin(\omega/2)}\right|, \qquad \theta(\omega) = -2\omega \;\; \text{(plus } \pi \text{ after } 2\pi/5 \text{, and again after } 4\pi/5\text{)}.
\omega 0 \pi/5 2\pi/5 \pi/2 4\pi/5 \pi
\lvert H(e^{j\omega})\rvert 1 0.647 \mathbf{0} 0.2 \mathbf{0} 0.2

The zeros are at \omega = 2\pi/5 and 4\pi/5. At \omega = 0 the gain is exactly 1, so DC passes untouched, and the gain is small at high frequencies. That confirms it is a low-pass filter.

6. Steady-state and transient response

Syllabus 4.8.5.

When an input is switched on, the output has two parts:

y[n] = y_{tr}[n] + y_{ss}[n].

The transient y_{tr}[n] is the system's temporary reaction right after the input starts. The steady-state response y_{ss}[n] is what remains once the transient has died out. For a stable system y_{tr}[n] \to 0 as n \to \infty, so eventually y[n] \approx y_{ss}[n].

6a. Worked example (note p.18): h[n] = \{4, -5, 6, -3\} with a unit-step input

The system is y[n] = 4x[n] - 5x[n-1] + 6x[n-2] - 3x[n-3]. With x[n] = u[n], every input from n = 0 on is 1, so the output just accumulates the taps:

\begin{aligned} y[0] &= 4, \\ y[1] &= 4 - 5 = -1, \\ y[2] &= 4 - 5 + 6 = 5, \\ y[3] &= 4 - 5 + 6 - 3 = 2, \\ y[n] &= 2 \quad\text{for every } n \ge 3. \end{aligned}

The steady-state value is 2 = \sum_n h[n] = H(e^{j0}). That makes sense: a step is a "zero-frequency" input, so in steady state it is simply multiplied by the gain at \omega = 0. The first three outputs, \{4, -1, 5\}, are the transient. In general an FIR filter of length L has a transient lasting L - 1 samples.

7. Response to a causal exponential

Syllabus 4.8.6. A derivation.

This is the precise version of Section 6: what exactly does the transient look like when e^{j\omega n} is switched on at n = 0?

In the exam, write:

Let the input be x[n] = e^{j\omega n}u[n] and let the system be causal, so h[k] = 0 for k < 0. Then

y[n] = \sum_{k=0}^{\infty} h[k]\,e^{j\omega(n-k)}\,u[n-k].

Since u[n-k] = 0 for k > n, only 0 \le k \le n contributes:

y[n] = e^{j\omega n}\sum_{k=0}^{n} h[k]\,e^{-j\omega k}.

This is not H(e^{j\omega}) yet, because the sum stops at n instead of \infty. Write it as "the whole infinite sum minus its tail":

\begin{aligned} y[n] &= e^{j\omega n}\left(\sum_{k=0}^{\infty} h[k]\,e^{-j\omega k} - \sum_{k=n+1}^{\infty} h[k]\,e^{-j\omega k}\right) \\[6pt] &= \underbrace{H(e^{j\omega})\,e^{j\omega n}}_{y_{ss}[n]}\;\underbrace{-\;e^{j\omega n}\sum_{k=n+1}^{\infty} h[k]\,e^{-j\omega k}}_{y_{tr}[n]}. \end{aligned}

The size of the transient is bounded by the tail of the impulse response:

|y_{tr}[n]| \le \sum_{k=n+1}^{\infty} |h[k]|.

If the system is stable, h[n] is absolutely summable, so this tail goes to 0 as n \to \infty and y[n] \to y_{ss}[n]. For an FIR filter whose h[n] is nonzero only for 0 \le n \le N, the tail is empty once n \ge N, so the transient is exactly zero after N samples.

8. The concept of filtering

Syllabus 4.8.7.

Think of an LTI system as a row of volume knobs, one per frequency. |H(e^{j\omega})| is the setting of the knob at \omega:

  • |H| \approx 1: that frequency passes unchanged.
  • |H| < 1: it is attenuated, and |H| \approx 0 removes it.
  • |H| > 1: it is amplified.

The range of frequencies a filter lets through is its passband; the range it suppresses is its stopband.

Type Lets through Shape of \lvert H\rvert on 0 \le \omega \le \pi
Low-pass (e.g. moving average) small \lvert\omega\rvert high at 0, low at \pi
High-pass large \lvert\omega\rvert near zero at 0, high at \pi
Band-pass a middle band a bump in the middle
Band-stop (notch) low and high a dip in the middle

A quick way to classify any filter is to compute the two ends: H(e^{j0}) = \sum_n h[n] and H(e^{j\pi}) = \sum_n (-1)^n h[n]. Large at 0 and small at \pi means low-pass; the reverse means high-pass.

The ideal low-pass filter has

|H(e^{j\omega})| = \begin{cases} 1, & 0 \le |\omega| \le \omega_c, \\ 0, & \omega_c < |\omega| \le \pi. \end{cases}

Feed it x[n] = A\cos\omega_1 n + B\cos\omega_2 n with \omega_1 < \omega_c < \omega_2, and only the low-frequency term survives:

y[n] = A\,|H(e^{j\omega_1})|\cos\big(\omega_1 n + \theta(\omega_1)\big).

Why can't an ideal filter be built? (past paper 2d) Its impulse response is

h_{LP}[n] = \frac{\sin\omega_c n}{\pi n}, \qquad -\infty < n < \infty,

which is infinitely long and nonzero for n < 0. It is non-causal and has no finite realisation, so in practice it can only be approximated.

8a. Design example (note p.20): block \omega = 0.1, pass \omega = 0.4

We want a 3-tap filter that completely removes the component at 0.1 rad/sample and passes the one at 0.4 rad/sample unchanged. Use a symmetric impulse response, h[0] = h[2] = \alpha_0 and h[1] = \alpha_1, because symmetry gives linear phase:

H(e^{j\omega}) = \alpha_0 + \alpha_1e^{-j\omega} + \alpha_0e^{-j2\omega} = e^{-j\omega}\big(\alpha_1 + 2\alpha_0\cos\omega\big).

So |H(e^{j\omega})| = |\alpha_1 + 2\alpha_0\cos\omega| and \theta(\omega) = -\omega. The two requirements give two equations:

\begin{aligned} 2\alpha_0\cos(0.1) + \alpha_1 &= 0 &&\text{(i) remove } 0.1, \\ 2\alpha_0\cos(0.4) + \alpha_1 &= 1 &&\text{(ii) pass } 0.4. \end{aligned}

Subtracting (i) from (ii) eliminates \alpha_1:

\alpha_0 = \frac{1}{2\big(\cos 0.4 - \cos 0.1\big)} = -6.762, \qquad \alpha_1 = -2\alpha_0\cos(0.1) = 13.456.
\boxed{y[n] = -6.762\,x[n] + 13.456\,x[n-1] - 6.762\,x[n-2]}

Check: |H(e^{j0.1})| = 0 and |H(e^{j0.4})| = 1.000. It blocks the lower frequency and passes the higher one, so this is a high-pass filter.

The ROC checklist (sir cuts marks for any missing ROC)

Where an ROC must appear:

  1. Every X(z), H(z) and Y(z) you write, including the intermediate ones on the way to the answer, not only the final line.
  2. Every table pair you quote. The pair is the formula together with its ROC.
  3. Every property you use. Linearity and convolution give "at least \text{ROC}_1 \cap \text{ROC}_2". A time shift keeps the ROC "except possibly z = 0 or z = \infty". Multiplying by a^n scales the ROC by |a|. Time reversal turns |z| > r into |z| < 1/r.
  4. Every inverse transform. Say which ROC you are using and what it implies, for example "ROC |z| > 2, so both terms are right-sided".
  5. Every system function. If the question gives no ROC, write "assuming the system is causal, ROC: |z| > (largest pole magnitude)", then compare it with the unit circle to judge stability.
  6. Finite sequences. Only negative powers of z: "all z except z = 0". Only positive powers: "all z except z = \infty". Both: "all z except 0 and \infty". For \delta[n]: "the entire z-plane".
  7. Every pole-zero plot. Shade the ROC and draw the dashed unit circle.

How to write it:

  • Use magnitudes: |z| > |a|, never z > a. Since z is complex, "z > a" has no meaning.
  • Use strict inequalities. The ROC never includes the circle through a pole.
  • Add a one-word reason: "(right-sided)", "(left-sided)", "(two-sided, a ring)" or "(finite length)".
  • If there is no ROC, say so: "the two regions do not overlap, so X(z) does not exist".

0. The whole topic in six sentences

  1. The z-transform is X(z) = \sum_n x[n]\,z^{-n}, where z = re^{j\omega} can be any complex number. On the unit circle (r = 1) it is exactly the DTFT.
  2. The region of convergence (ROC) is the set of z for which that sum converges. The same formula with a different ROC is a different signal.
  3. Right-sided signals have an ROC outside a circle, left-sided signals have one inside a circle, and two-sided signals have a ring, or no ROC at all.
  4. Poles are where X(z) is infinite and zeros are where it is zero. The ROC never contains a pole.
  5. For an LTI system Y(z) = H(z)\,X(z), which turns a difference equation into algebra.
  6. A system is stable exactly when its ROC contains the unit circle. A causal system is stable exactly when all its poles are inside the unit circle.

1. Why do we need the z-transform?

A 2-mark "define" question.

The DTFT, X(e^{j\omega}) = \sum_n x[n]\,e^{-j\omega n}, does not converge for every signal. For a growing exponential such as 2^n u[n] the sum blows up, because |e^{-j\omega n}| = 1 does nothing to hold the growth back. The z-transform replaces e^{j\omega}, which is stuck on the unit circle, with a general complex number z = re^{j\omega} of any size. That brings in an extra factor r^{-n}, which can overpower the growth if r is large enough. So the z-transform is a generalisation of the DTFT.

Definition.

X(z) = \sum_{n=-\infty}^{\infty} x[n]\,z^{-n}, \qquad \text{ROC} = \{\, z : X(z) \text{ converges} \,\}.

How is it related to the DTFT and the DFT? (final 4b) The DTFT is the z-transform evaluated on the unit circle, and the DFT samples that circle at N equally spaced points:

X(e^{j\omega}) = X(z)\Big|_{z = e^{j\omega}}, \qquad X[k] = X(z)\Big|_{z = e^{j2\pi k/N}}.

2. Finite-length sequences (Proakis Ex 3.1.1)

A likely warm-up part.

For a finite sequence the z-transform is just a polynomial: each sample x[n] becomes the term x[n]\,z^{-n}. The arrow marks the sample at n = 0.

x[n] X(z) ROC
\{\underset{\uparrow}{1}, 2, 5, 7, 0, 1\} 1 + 2z^{-1} + 5z^{-2} + 7z^{-3} + z^{-5} all z except z = 0
\{1, 2, \underset{\uparrow}{5}, 7, 0, 1\} z^2 + 2z + 5 + 7z^{-1} + z^{-3} all z except z = 0 and z = \infty
\{\underset{\uparrow}{0}, 0, 1, 2, 5, 7, 0, 1\} z^{-2} + 2z^{-3} + 5z^{-4} + 7z^{-5} + z^{-7} all z except z = 0

The rule behind the ROC column: a negative power such as z^{-1} = 1/z blows up at z = 0, and a positive power such as z blows up at z = \infty. Look at which powers appear and exclude those points.

3. The infinite sequences you must be able to derive

Proakis Ex 3.1.2, 3.1.3 and 3.1.5. Everything later is built from these.

3a. Causal exponential: x[n] = a^n u[n]

Only n \ge 0 contributes, and the sum is a geometric series in az^{-1}:

X(z) = \sum_{n=0}^{\infty} a^n z^{-n} = \sum_{n=0}^{\infty}\big(az^{-1}\big)^n = \frac{1}{1 - az^{-1}} = \frac{z}{z - a}.

A geometric series converges when its ratio has magnitude less than 1, so we need |az^{-1}| < 1:

\text{ROC: } |z| > |a| \qquad \text{(outside the circle of radius } |a|\text{)}.

Example 3.1.2 is the case a = \tfrac12: X(z) = 1/(1 - \tfrac12 z^{-1}) with ROC |z| > \tfrac12.

The pole-zero plot, drawn for a = 0.6. Writing X(z) = \frac{z}{z - a} shows a zero at the origin and a pole at a. The ROC is shaded outside the circle through the pole, and the dashed circle is the unit circle.

3b. Anti-causal exponential: x[n] = -a^n u[-n-1]

Now only n \le -1 contributes. Substitute \ell = -n so that the sum runs over positive \ell:

\begin{aligned} X(z) &= \sum_{n=-\infty}^{-1}\big(-a^n\big)z^{-n} = -\sum_{\ell=1}^{\infty}\big(a^{-1}z\big)^{\ell} \\[4pt] &= -\frac{a^{-1}z}{1 - a^{-1}z} \qquad \Big(\text{using } A + A^2 + A^3 + \cdots = \frac{A}{1 - A}\Big) \\[4pt] &= \frac{z}{z - a} = \frac{1}{1 - az^{-1}}. \end{aligned}

This converges when |a^{-1}z| < 1:

\text{ROC: } |z| < |a| \qquad \text{(inside the circle of radius } |a|\text{)}.

Exactly the same pole and zero as in 3a. Only the shading moves, to inside the circle.

The punchline. Write this sentence in the exam. Sections 3a and 3b give the same closed form but different ROCs. A closed-form expression on its own does not pin down the signal: a discrete-time signal is uniquely determined by its z-transform together with its ROC.

3c. Two-sided: x[n] = a^n u[n] + b^n u[-n-1]

Final 6a (10 marks) and 4f. The most likely full question in this topic.

Split it into its causal part and its anti-causal part, and use the sums from above:

X(z) = \sum_{n=0}^{\infty}\big(az^{-1}\big)^n + \sum_{\ell=1}^{\infty}\big(b^{-1}z\big)^{\ell} = \frac{1}{1 - az^{-1}} - \frac{1}{1 - bz^{-1}}.

The first sum needs |z| > |a| and the second needs |z| < |b|. Both must hold at the same time, so there are two cases.

Case 1: |b| \le |a|. "Outside |a|" and "inside |b|" do not overlap, so there is no ROC and X(z) does not exist.

Case 2: |a| < |b|. The two regions overlap in a ring, and

\text{ROC: } |a| < |z| < |b|, \qquad X(z) = \frac{(a - b)\,z^{-1}}{(1 - az^{-1})(1 - bz^{-1})}.

Your note writes the same thing as \dfrac{b - a}{a + b - z - abz^{-1}}; multiply the top and bottom by z to see that they agree.

Sketching the ROC. Draw two concentric circles of radius |a| and |b| and shade the ring between them. For Case 1, draw the two regions and show that they do not touch.

Case 2, drawn for a = 0.5 and b = 1.5: poles at a and b, a zero at the origin, and the ROC is the ring between the two circles.

Check: with a = 0.5, b = 2 and z = 1.2 (inside the ring), the closed form and the summed series both give X = 3.2143.

3d. Sum of two causal exponentials (Ex 3.2.1): x[n] = \big[3(2^n) - 4(3^n)\big]u[n]

Use linearity and the pair from 3a on each term:

X(z) = \frac{3}{1 - 2z^{-1}} - \frac{4}{1 - 3z^{-1}}.

The first term needs |z| > 2 and the second needs |z| > 3. The ROC of the sum is where both converge, which is the intersection: |z| > 3.

6. Poles and zeros

Final 4a, 5f and 6b.

Definitions (2 marks). The zeros of X(z) are the values of z at which X(z) = 0. The poles are the values at which X(z) = \infty. On a pole-zero plot, poles are marked \times and zeros \circ.

For a rational X(z) whose numerator has degree M and denominator degree N in powers of z^{-1}, factor it as

X(z) = \frac{B(z)}{A(z)} = G\,z^{N-M}\,\frac{\prod_{k=1}^{M}(z - z_k)}{\prod_{k=1}^{N}(z - p_k)}.
  • If N > M, the factor z^{N-M} gives N - M extra zeros at the origin. If N < M, it gives M - N extra poles at the origin.
  • If you count the ones at 0 and \infty too, the number of zeros always equals the number of poles.
  • When the coefficients are real, complex poles and zeros come in conjugate pairs.

How to draw any pole-zero plot

Follow these steps in order. The figures in Sections 3a–3c, 6a and 6b are all drawn this way.

  1. Rewrite X(z) in positive powers of z. Multiply the top and bottom by the highest power of z that clears the negative powers. For example, \dfrac{1}{1 - az^{-1}} = \dfrac{z}{z - a}.
  2. Find the zeros and poles. Set the numerator to zero and solve: those are the zeros. Set the denominator to zero and solve: those are the poles.
  3. Don't forget the origin. A leftover factor z^k on top is a k-fold zero at z = 0; on the bottom it is a k-fold pole at z = 0. This is the mark people lose most often.
  4. Draw the axes and the unit circle. Draw the real and imaginary axes, then the unit circle |z| = 1 as a dashed circle.
  5. Mark them. Mark each pole with \times and each zero with \circ. Write the multiplicity next to a repeated one, such as "(2)" or "(7)".
  6. Check the symmetry. With real coefficients, complex poles and zeros come in conjugate pairs, so the plot is a mirror image across the real axis.
  7. Shade the ROC. It is bounded by circles through the poles and never contains a pole. A causal (right-sided) signal is shaded outside the outermost pole, an anti-causal (left-sided) one inside the innermost pole, and a two-sided one gets the ring between two poles.
  8. Read off stability. If the dashed unit circle lies inside the shaded region, the system is stable (Section 7).

Quick check: counting the ones at 0 and \infty, there are as many zeros as poles.

6a. Worked example (note p.32): X(z) = \dfrac{z(2z^2 - 2z + 1)}{16z^3 + 6z + 5}

Zeros. One is at z = 0; the quadratic gives the other two:

2z^2 - 2z + 1 = 0 \quad\Longrightarrow\quad z = \frac{2 \pm \sqrt{4 - 8}}{4} = 0.5 \pm 0.5j.

Poles. Try z = -0.5 in the cubic: 16(-0.125) + 6(-0.5) + 5 = -2 - 3 + 5 = 0, so it is a root. Dividing 16z^3 + 6z + 5 by (z + 0.5) leaves 16z^2 - 8z + 10, whose roots are

z = \frac{8 \pm \sqrt{64 - 640}}{32} = 0.25 \pm 0.75j.

So the poles are z = -0.5 and z = 0.25 \pm 0.75j.

If the system is causal, the ROC is outside the outermost pole: |z| > |0.25 \pm 0.75j| = \sqrt{0.0625 + 0.5625} = 0.79. That region includes the unit circle, so the system is stable.

Only the upper member of each conjugate pair is labelled; its mirror image is directly below it. The dashed unit circle sits inside the shaded ROC, so the system is stable.

6b. Final 6b (10 marks): x[n] = a^n for 0 \le n \le M-1, zero otherwise

Find the z-transform and draw the pole-zero plot.

It is a finite geometric series:

X(z) = \sum_{n=0}^{M-1}\big(az^{-1}\big)^n = \frac{1 - a^M z^{-M}}{1 - az^{-1}} = \frac{z^M - a^M}{z^{M-1}(z - a)}.

The sequence is finite and causal, so the ROC is |z| > 0: everything except the origin.

Zeros. z^M = a^M has M solutions, equally spaced around a circle of radius |a|:

z_k = a\,e^{j2\pi k/M}, \qquad k = 0, 1, \ldots, M-1.

Poles. z^{M-1} = 0 gives M - 1 poles at the origin, and z - a = 0 gives one pole at z = a.

But the zero for k = 0 is z_0 = a, exactly where that last pole sits, so the two cancel. The final answer is

\boxed{M - 1 \text{ zeros at } z_k = a\,e^{j2\pi k/M},\ k = 1, \ldots, M-1; \qquad M - 1 \text{ poles at } z = 0}

6c. The significance of poles and zeros (final 5f, 5 marks)

  • Poles set the natural behaviour of h[n]. A real pole p contributes a term like p^n. A complex pair re^{\pm j\omega_0} contributes r^n\cos(\omega_0 n + \phi), which oscillates.
  • A pole's distance from the origin decides growth or decay. Inside the unit circle the term decays (stable); on the circle it neither grows nor decays; outside, it grows (unstable). The closer a pole is to |z| = 1, the slower the decay and the sharper the peak in |H|.
  • Angles matter too. A pole at angle \omega_0 makes |H(e^{j\omega})| peak near \omega_0 (resonance). A zero on the unit circle at angle \omega_0 makes |H(e^{j\omega_0})| = 0 (a notch).
  • The geometric picture. |H(e^{j\omega})| is proportional to the product of the distances from the point e^{j\omega} to the zeros, divided by the product of the distances to the poles.
  • A causal system is stable exactly when all its poles are inside the unit circle.

7. The system function and stability

The z-transform of the impulse response is the system function, h[n] \longleftrightarrow H(z). Convolution becomes multiplication, so

Y(z) = H(z)\,X(z) \qquad\Longrightarrow\qquad H(z) = \frac{Y(z)}{X(z)}.

For a system described by a linear constant-coefficient difference equation,

y[n] = -\sum_{k=1}^{N} a_k\,y[n-k] + \sum_{k=0}^{M} b_k\,x[n-k],

transform each term (each delay becomes a factor z^{-k}) and solve for Y/X:

H(z) = \frac{\sum_{k=0}^{M} b_k z^{-k}}{1 + \sum_{k=1}^{N} a_k z^{-k}}.

This is called a rational system function. Stability, the second half of this section, starts at 7c.

7a. Ex 3.3.4, which came as final 5a: y[n] = \tfrac12 y[n-1] + 2x[n]

Find the system function and the unit sample response.

Take the z-transform of both sides; a one-sample delay becomes a factor z^{-1}:

Y(z) = \tfrac12 z^{-1}Y(z) + 2X(z) \quad\Longrightarrow\quad Y(z)\big(1 - \tfrac12 z^{-1}\big) = 2X(z) \quad\Longrightarrow\quad \boxed{H(z) = \frac{2}{1 - \tfrac12 z^{-1}}}

This has a pole at z = \tfrac12 and a zero at z = 0. Taking the system as causal, the ROC is |z| > \tfrac12. With that ROC, the pair a^n u[n] \leftrightarrow 1/(1 - az^{-1}) gives the inverse:

\boxed{h[n] = 2\left(\tfrac12\right)^n u[n]} = \{\underset{\uparrow}{2}, 1, 0.5, 0.25, \ldots\}.

The pole at \tfrac12 is inside the unit circle, so the system is stable. Its DC gain is H(1) = 2/(1 - \tfrac12) = 4.

7b. An FIR example: y[n] = 3x[n] - 4x[n-1] + x[n-2]

There is no feedback, so H(z) is simply the polynomial of the taps, and h[n] is the list of taps:

H(z) = 3 - 4z^{-1} + z^{-2} \quad\Longrightarrow\quad h[n] = 3\delta[n] - 4\delta[n-1] + \delta[n-2] = \{\underset{\uparrow}{3}, -4, 1\}.

ROC: all z except z = 0, because H(z) has only negative powers of z (finite length). An FIR filter is always stable.

7c. What "stable" means, and why the poles decide it

Forget the z-plane for a moment. Kick the system once with an impulse and watch what comes out. That output is h[n], the system's ringing. A stable system's ringing dies away; an unstable one rings louder and louder forever. The precise definition (BIBO stability) says the total size of the ringing is finite:

\sum_{n} |h[n]| < \infty.

Everything else in this section is a shortcut for checking that without working out all of h[n].

The shortcut. Partial fractions (Section 8) split any rational H(z) into one simple piece per pole:

H(z) = \frac{A_1}{1 - p_1 z^{-1}} + \frac{A_2}{1 - p_2 z^{-1}} + \cdots

For a causal system each piece is a geometric sequence, so the impulse response is just a sum of powers of the poles:

h[n] = A_1\,p_1^n + A_2\,p_2^n + \cdots, \qquad n \ge 0.

Now ask what happens to p^n as n grows. Only the size of p matters:

  • |p| < 1: p^n shrinks towards zero, like 0.5, 0.25, 0.125, \ldots
  • |p| = 1: p^n keeps the same size forever, like 1, 1, 1, \ldots
  • |p| > 1: p^n grows without limit, like 2, 4, 8, \ldots

The unit circle is simply the set of points with |z| = 1, the border between "powers shrink" and "powers grow". So for a causal system:

A causal system is stable if and only if every pole is inside the unit circle. There is no complex analysis in this: it just says every p^n must shrink.

A complex pair of poles re^{\pm j\theta} gives a term like r^n\cos(\theta n + \phi): a wave inside the envelope r^n. The angle \theta sets how fast it wiggles; the radius r alone decides whether it dies. That is why only a pole's distance from the origin matters for stability.

In each row the pole is on the left and the impulse response it produces is on the right. Inside the unit circle the response dies out, on the circle it never dies, and outside it grows. A red arrow means the value has run off the top of the plot.

7d. The textbook version: "the ROC contains the unit circle"

Your note states the rule differently, as a fact about the ROC. It says the same thing, and you can see why using nothing but the size of z^{-n}.

Write z = re^{j\omega}. Then

z^{-n} = r^{-n}\,e^{-j\omega n}, \qquad\text{and}\qquad |e^{-j\omega n}| = 1.

So the angle \omega never affects whether the sum converges. In H(z) = \sum_n h[n]\,z^{-n}, each term has size |h[n]|\,r^{-n}. In other words, the z-transform reweights the impulse response by r^{-n}:

  • Outside the unit circle (r > 1), r^{-n} shrinks as n grows, so it helps a right-sided h[n] converge.
  • Inside the unit circle (r < 1), r^{-n} grows as n grows, so it works against convergence.
  • On the unit circle (r = 1), r^{-n} = 1, which neither helps nor hurts. The sum converges only if \sum_n |h[n]| is already finite on its own.

That last point is the whole theorem. "The ROC contains the unit circle" means "the sum converges with no help from r", which means \sum_n |h[n]| < \infty, which is exactly the definition of stable:

An LTI system is stable if and only if the ROC of H(z) contains the unit circle.

The inequality in your note just writes this down. The size of a sum is never more than the sum of the sizes (the triangle inequality), so

|H(z)| = \Big|\sum_n h[n]\,z^{-n}\Big| \;\le\; \sum_n |h[n]|\,|z^{-n}| \;=\; \sum_n |h[n]| \qquad \text{on } |z| = 1.

If the system is stable, the right-hand side is finite, so H(z) is finite everywhere on the unit circle. No Cauchy and no contour integrals are involved.

There is also a link to Topic 1: on the unit circle, H(z) is the frequency response H(e^{j\omega}). So a stable system is exactly one whose frequency response exists.

Why the two versions agree. A causal system's ROC is everything outside its outermost pole, |z| > \max_k |p_k|. That region contains the unit circle exactly when \max_k |p_k| < 1, which means every pole is inside the unit circle.

7e. Causal isn't the whole story: one H(z), three ROCs

"All poles inside the unit circle" is the test for causal systems only. The ROC version works for every system. Take

H(z) = \frac{1}{(1 - 0.5z^{-1})(1 - 2z^{-1})} = \frac{-1/3}{1 - 0.5z^{-1}} + \frac{4/3}{1 - 2z^{-1}},

which has poles at 0.5 and 2. Three ROCs are possible, and each one gives a different system:

Only the ring contains the unit circle, so only that system is stable, even though it has a pole outside the unit circle.

How can a pole at 2 be harmless? In the ring, that pole's piece is left-sided: -\tfrac43\,2^n u[-n-1]. For negative n, 2^n is \tfrac12, \tfrac14, \tfrac18, \ldots, so going back in time it dies away. The general rule: a right-sided piece needs its pole inside the unit circle, and a left-sided piece needs its pole outside it.

7f. What to write in the exam

An LTI system is BIBO stable if and only if \sum_n |h[n]| < \infty. Since |H(z)| \le \sum_n |h[n]|\,|z|^{-n}, which equals \sum_n |h[n]| on |z| = 1, the z-transform converges on the unit circle exactly when the system is stable. Hence an LTI system is stable if and only if the ROC of H(z) contains the unit circle. For a causal system the ROC is |z| > \max_k |p_k|, so a causal LTI system is stable if and only if all its poles lie inside the unit circle.

8. The inverse z-transform

There are three methods. Know all three names; the third is the one you will actually use.

  1. Power-series expansion: expand X(z) as a series in z^{-1} and read x[n] off as the coefficient of z^{-n}.
  2. Contour integration: x[n] = \dfrac{1}{2\pi j}\oint_C X(z)\,z^{n-1}\,dz. Just state it; nobody expects you to evaluate one in a 40-minute exam.
  3. Partial fractions and a table lookup: the workhorse.

8a. Power series: X(z) = \log(1 + az^{-1}) with |z| > |a|

Use the known series \log(1 + u) = u - \frac{u^2}{2} + \frac{u^3}{3} - \cdots with u = az^{-1}:

X(z) = \sum_{n=1}^{\infty}\frac{(-1)^{n+1}a^n}{n}\,z^{-n} \quad\Longrightarrow\quad x[n] = \begin{cases} \dfrac{(-1)^{n+1}a^n}{n}, & n \ge 1, \\[6pt] 0, & n \le 0. \end{cases}

This method is the natural choice when X(z) is a function whose series you already know: log, exp, sin, cos or a geometric series.

8b. Partial fractions with distinct poles: the "Imp for exam" problem

Question. x[n] = 2^n u[n] and h[n] = (0.5)^n u[n]. Find y[n] = x[n] * h[n] (1) in the time domain and (3) using the z-transform.

(1) Time domain. Both signals are zero for negative n, so the sum runs over 0 \le k \le n. Pull out (0.5)^n and what remains is a geometric series in 4:

\begin{aligned} y[n] &= \sum_{k=0}^{n} 2^k(0.5)^{n-k} = (0.5)^n\sum_{k=0}^{n} 4^k = (0.5)^n\,\frac{4^{n+1} - 1}{3} \\[4pt] &= \frac43\,2^n - \frac13\,(0.5)^n, \qquad n \ge 0. \end{aligned}

(3) z-domain. Transform both signals, multiply, and split by partial fractions:

X(z) = \frac{1}{1 - 2z^{-1}}, \ \ |z| > 2; \qquad H(z) = \frac{1}{1 - 0.5z^{-1}}, \ \ |z| > 0.5.
Y(z) = X(z)\,H(z) = \frac{1}{(1 - 2z^{-1})(1 - 0.5z^{-1})} = \frac{z^2}{(z - 2)(z - 0.5)}, \qquad |z| > 2.

Divide by z first (the steps below explain why):

\frac{Y(z)}{z} = \frac{z}{(z - 2)(z - 0.5)} = \frac{A}{z - 2} + \frac{B}{z - 0.5}.

Find A and B by the cover-up rule, putting z equal to each pole in turn:

A = \frac{2}{2 - 0.5} = \frac43, \qquad B = \frac{0.5}{0.5 - 2} = -\frac13.

Multiply back by z and read off the table. Both terms are causal because the ROC is |z| > 2:

Y(z) = \frac{4/3}{1 - 2z^{-1}} - \frac{1/3}{1 - 0.5z^{-1}} \quad\Longrightarrow\quad \boxed{y[n] = \frac43\,2^n u[n] - \frac13\,(0.5)^n u[n]}

Both methods agree, and so does a direct numerical convolution: y[n] = \{1,\ 2.5,\ 5.25,\ 10.625,\ \ldots\}.

(2) "Frequency domain" is a trap. Your note writes X(e^{j\omega}) = 1/(1 - 2e^{-j\omega}), but that DTFT does not exist. 2^n u[n] is not absolutely summable, and its ROC |z| > 2 does not contain the unit circle. If sir asks for this method, write the principle Y(e^{j\omega}) = X(e^{j\omega})\,H(e^{j\omega}) and then add:

"Since the ROC |z| > 2 excludes |z| = 1, the DTFT of 2^n u[n] does not converge, so the z-transform must be used. This is exactly why the z-transform generalises the DTFT."

That sentence turns his trap into marks.

The four steps of any partial-fraction inverse (writing them at the top of your answer earns method marks):

  1. Find the poles p_1, \ldots, p_K and how many times each one repeats.
  2. Expand X(z)/z, not X(z). That keeps the fraction proper, and after you multiply back by z every term has the form \dfrac{z}{z - p}.
  3. Find the coefficients with the cover-up rule (set z equal to a pole) or by comparing coefficients.
  4. Multiply back by z, rewrite each \dfrac{z}{z - p} as \dfrac{1}{1 - pz^{-1}}, and look it up. Whether a term becomes p^n u[n] or -p^n u[-n-1] is decided by the ROC.

8c. Partial fractions with a repeated pole

A pole at z = -2 and a double pole at z = 1.

X(z) = \frac{1}{(1 + 2z^{-1})(1 - z^{-1})^2} \quad\Longrightarrow\quad \frac{X(z)}{z} = \frac{z^2}{(z + 2)(z - 1)^2} = \frac{A}{z + 2} + \frac{B}{z - 1} + \frac{C}{(z - 1)^2}.

z^2 = A(z - 1)^2 + B(z - 1)(z + 2) + C(z + 2).

Two questions decide which tool you use: is time continuous or discrete, and is the signal periodic or not?

Periodic signal Aperiodic signal
Continuous time CTFS: c_k = \frac{1}{T_0}\int_{T_0} x(t)e^{-j2\pi kF_0t}dt CTFT: X(F) = \int x(t)e^{-j2\pi Ft}dt
Discrete time DTFS: c_k = \frac1N\sum_{n=0}^{N-1} x[n]e^{-j2\pi kn/N} DTFT: X(\omega) = \sum_n x[n]e^{-j\omega n}

The duality: periodic in time means a discrete (line) spectrum, and discrete time means a periodic spectrum. That is why the DTFT always repeats every 2\pi.

2. Square wave, CTFS (5 min)

An even \pm1 square wave with period T_0: +1 for |t| < T_0/4, -1 for the rest of the period.

Because x(t) is even, only the cosine part survives:

c_k = \frac{2}{T_0}\left[\int_0^{T_0/4}\cos(k\Omega_0t)\,dt - \int_{T_0/4}^{T_0/2}\cos(k\Omega_0t)\,dt\right] = \frac{4\sin(k\pi/2)}{k\Omega_0T_0}.

With \Omega_0T_0 = 2\pi:

\boxed{c_k = \frac{2}{k\pi}\sin\frac{k\pi}{2}}

Then say what it means: c_0 = 0 (no DC, equal time at +1 and -1); even harmonics are zero; odd harmonics fall off like 1/k, with c_1 = 0.637, c_3 = -0.212, c_5 = 0.127.

3. Rectangular pulse, CTFT (4 min)

x(t) = A for |t| < \tau/2, zero otherwise.

X(F) = \int_{-\tau/2}^{\tau/2} A\,e^{-j2\pi Ft}\,dt = \boxed{A\tau\,\frac{\sin(\pi F\tau)}{\pi F\tau} = A\tau\operatorname{sinc}(F\tau)}

Three facts to write: X(0) = A\tau, the area of the pulse; zeros at F = \pm1/\tau, \pm2/\tau, \ldots; and a wider pulse gives a narrower spectrum (the time–bandwidth trade-off).

4. Discrete-time periodicity and the DTFS (4 min)

The test: \cos(\omega_0 n) is periodic only if f_0 = \dfrac{\omega_0}{2\pi} is a ratio of integers k/N. The period is the smallest such N.

  • \cos(\pi n/3): f_0 = 1/6, so N = 6.
  • \cos(\sqrt2\,\pi n): f_0 = 1/\sqrt2 is irrational, so it is not periodic.
  • \cos(n/6): f_0 = 1/(12\pi) is irrational, so it is not periodic either (a favourite trick).

DTFS of \cos(\pi n/3): write it with Euler and match terms with \sum_k c_k e^{j2\pi kn/6}:

\cos\frac{2\pi n}{6} = \tfrac12 e^{j2\pi n/6} + \tfrac12 e^{-j2\pi n/6} = \tfrac12 e^{j2\pi(1)n/6} + \tfrac12 e^{j2\pi(5)n/6}.

So \boxed{c_1 = c_5 = \tfrac12}, and all the other c_k are zero. Only N coefficients exist because c_{k+N} = c_k.

5. DTFT of a^n u[n] (3 min)

A geometric series, convergent because |a| < 1:

X(\omega) = \sum_{n=0}^{\infty}\big(ae^{-j\omega}\big)^n = \boxed{\frac{1}{1 - ae^{-j\omega}}}, \qquad |X(\omega)|^2 = \frac{1}{1 - 2a\cos\omega + a^2}.

|X(\omega)|^2 is the energy density spectrum. With a = 0.5 it is 4 at \omega = 0 and 0.444 at \omega = \pi: the energy sits at low frequencies, a low-pass signal.

The DTFT exists only if \sum|x[n]| < \infty. 2^n u[n] and u[n] have no DTFT. If asked, say: "not absolutely summable; the ROC does not contain the unit circle".

6. Energy, power and Parseval (4 min)

\boxed{E = \sum_n |x[n]|^2 = \frac{1}{2\pi}\int_{-\pi}^{\pi}|X(\omega)|^2\,d\omega} \qquad\qquad \boxed{P = \frac1N\sum_{n=0}^{N-1}|x[n]|^2 = \sum_{k=0}^{N-1}|c_k|^2}

The left one is for aperiodic signals, the right one for periodic signals. In words: the energy (or power) is the same whether you add it up over time or over frequency.

Worked examples sir has used:

  • x(t) = e^{-0.6t}u(t): E = \int_0^\infty e^{-1.2t}dt = \dfrac{1}{1.2} = 0.8333 J.
  • x[n] = (-1)^n: every |x[n]|^2 = 1, so E = \infty but P = 1. It is a power signal, and all of it sits at \omega = \pi.
  • u[n]: E = \infty and P = \tfrac12, because it is on for only half of the window from -N to N.

7. Properties (4 min)

Property x[n] X(\omega)
Time shift x[n-k] e^{-j\omega k}X(\omega): only the phase changes
Frequency shift e^{j\omega_0n}x[n] X(\omega - \omega_0)
Modulation x[n]\cos\omega_0n \tfrac12[X(\omega - \omega_0) + X(\omega + \omega_0)]
Convolution x_1[n] * x_2[n] X_1(\omega)X_2(\omega)
Time reversal x[-n] X(-\omega)
Real x[n] X(-\omega) = X^*(\omega): \lvert X\rvert even, phase odd

Proof of the time shift (the one most likely to be asked). Substitute m = n - k:

\sum_n x[n-k]\,e^{-j\omega n} = e^{-j\omega k}\sum_m x[m]\,e^{-j\omega m} = e^{-j\omega k}X(\omega).

The frequency shift is the same idea: \sum_n e^{j\omega_0n}x[n]e^{-j\omega n} = \sum_n x[n]e^{-j(\omega-\omega_0)n} = X(\omega - \omega_0).

8. Two one-liners (2 min)

DTFT and z-transform. The DTFT is the z-transform on the unit circle:

X(\omega) = X(z)\big|_{z = e^{j\omega}} \qquad \text{(only if the ROC contains } |z| = 1\text{)}.

Dirichlet conditions (when the Fourier series or transform converges): finitely many finite discontinuities; finitely many maxima and minima; and x(t) absolutely integrable, \int|x(t)|\,dt < \infty. At a jump, the series converges to the midpoint.

0. The whole topic in one table

Draw this first in any "explain" answer.

There are four Fourier tools, one for each combination of continuous or discrete time with a periodic or aperiodic signal.

Periodic signal (discrete spectrum) Aperiodic signal (continuous spectrum)
Continuous time (aperiodic spectrum) CTFS: c_k = \frac{1}{T_p}\int_{T_p} x(t)\,e^{-j2\pi kF_0t}\,dt CTFT: X(F) = \int_{-\infty}^{\infty} x(t)\,e^{-j2\pi Ft}\,dt
Discrete time (periodic spectrum) DTFS: c_k = \frac{1}{N}\sum_{n=0}^{N-1} x[n]\,e^{-j2\pi kn/N} DTFT: X(\omega) = \sum_{n=-\infty}^{\infty} x[n]\,e^{-j\omega n}

The matching synthesis (inverse) formulas are

\begin{aligned} \text{CTFS:}\quad & x(t) = \sum_{k=-\infty}^{\infty} c_k\,e^{j2\pi kF_0t} \\ \text{CTFT:}\quad & x(t) = \int_{-\infty}^{\infty} X(F)\,e^{j2\pi Ft}\,dF \\ \text{DTFS:}\quad & x[n] = \sum_{k=0}^{N-1} c_k\,e^{j2\pi kn/N} \\ \text{DTFT:}\quad & x[n] = \frac{1}{2\pi}\int_{2\pi} X(\omega)\,e^{j\omega n}\,d\omega \end{aligned}

The pattern to remember is a duality: periodic in one domain means discrete in the other, and discrete in one domain means periodic in the other.

Vocabulary (note p.34):

  • Frequency analysis: breaking a signal down into its frequency components.
  • Harmonics: the frequencies kF_0, the integer multiples of the fundamental F_0.
  • Bandwidth: the range of frequencies where the signal's energy or power is concentrated.
  • Resonance: a system's tendency to respond with a much larger amplitude at certain frequencies.

Examples: a sinusoidal carrier is periodic, an ECG is aperiodic, speech is aperiodic, and machine vibration is periodic.

1. The continuous-time Fourier series

Any periodic signal x(t) with period T_0, so fundamental \Omega_0 = 2\pi/T_0, can be written as a weighted sum of complex exponentials at the harmonic frequencies k\Omega_0:

x(t) = \sum_{k=-\infty}^{\infty} c_k\,e^{jk\Omega_0 t}, \qquad c_k = \frac{1}{T_0}\int_{T_0} x(t)\,e^{-jk\Omega_0 t}\,dt.

The coefficient c_k tells you how much of harmonic k the signal contains.

1a. Spectra you can read off by inspection (note p.35)

If the signal is already a sum of sinusoids, Euler's formula gives the coefficients without any integration:

\cos\Omega_0 t = \tfrac12 e^{j\Omega_0 t} + \tfrac12 e^{-j\Omega_0 t} \quad\Longrightarrow\quad c_1 = c_{-1} = \tfrac12, \ \text{all others } 0.

In particular c_0 = 0: a pure cosine has no DC part. With an amplitude and a phase,

A\cos(\Omega_0 t + \phi) \quad\Longrightarrow\quad c_1 = \tfrac{A}{2}e^{j\phi}, \qquad c_{-1} = \tfrac{A}{2}e^{-j\phi} = c_1^*.

That relation c_{-k} = c_k^* is the conjugate symmetry every real signal has. The magnitude plot is two lines of height A/2 at \pm\Omega_0; the phase plot is +\phi at +\Omega_0 and -\phi at -\Omega_0.

1b. The \pm 1 square wave: full derivation

An even square wave with period T_0: x(t) = +1 for |t| < T_0/4 and -1 for T_0/4 < |t| < T_0/2.

Integrate over one period centred on zero. Because x(t) is even and sine is odd, the sine part of e^{-jk\Omega_0 t} integrates to zero and the cosine part doubles over the half-period:

\begin{aligned} c_k &= \frac{1}{T_0}\int_{-T_0/2}^{T_0/2} x(t)\,e^{-jk\Omega_0 t}\,dt = \frac{2}{T_0}\int_0^{T_0/2} x(t)\cos(k\Omega_0 t)\,dt \\[6pt] &= \frac{2}{T_0}\left[\int_0^{T_0/4}\cos(k\Omega_0 t)\,dt - \int_{T_0/4}^{T_0/2}\cos(k\Omega_0 t)\,dt\right] \\[6pt] &= \frac{2}{T_0}\cdot\frac{1}{k\Omega_0}\Big[\sin\tfrac{k\pi}{2} - 0 - \big(\sin k\pi - \sin\tfrac{k\pi}{2}\big)\Big] = \frac{4\sin(k\pi/2)}{k\Omega_0 T_0}. \end{aligned}

Since \Omega_0 T_0 = 2\pi,

\boxed{c_k = \frac{2}{k\pi}\,\sin\frac{k\pi}{2}}

Now read off what it says:

  • For k = 0: c_0 = 0. The wave spends equal time at +1 and -1, so its average is zero.
  • For even k: \sin(k\pi/2) = 0, so c_k = 0.
  • For odd k: c_k = \pm\frac{2}{k\pi}, so |c_k| = \frac{2}{\pi|k|}. That gives c_1 = 0.637, c_3 = -0.212, c_5 = 0.127, and so on.

Only the odd harmonics survive, and they shrink like 1/k.

A common variant is the 0/1 square wave with the same timing (50% duty cycle). It equals \tfrac12\big(x(t) + 1\big), so it has c_0 = \tfrac12 and c_k = \frac{1}{k\pi}\sin\frac{k\pi}{2} for k \ne 0.

2. The continuous-time Fourier transform

For an aperiodic signal, imagine a periodic one whose period T_p grows without limit. The harmonics crowd closer and closer together until the lines merge into a continuous spectrum. In angular frequency \Omega:

X(\Omega) = \int_{-\infty}^{\infty} x(t)\,e^{-j\Omega t}\,dt, \qquad x(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} X(\Omega)\,e^{j\Omega t}\,d\Omega.

In hertz, with \Omega = 2\pi F, the 2\pi disappears from the inverse:

X(F) = \int_{-\infty}^{\infty} x(t)\,e^{-j2\pi Ft}\,dt, \qquad x(t) = \int_{-\infty}^{\infty} X(F)\,e^{j2\pi Ft}\,dF.

The Dirichlet conditions (final 1c, "briefly demonstrate"). The series or the transform converges if:

  1. x(t) has a finite number of finite discontinuities in any finite interval (in one period, for the series);
  2. x(t) has a finite number of maxima and minima in that interval;
  3. x(t) is absolutely integrable, \int |x(t)|\,dt < \infty (over one period, for the series).

These conditions are sufficient, not necessary. When they hold, the series or transform converges to x(t) wherever x is continuous, and to the midpoint of the jump at a discontinuity.

2a. A rectangular pulse gives a sinc (Ex 4.1.2)

Let x(t) = A for |t| < \tau/2 and 0 otherwise. It is aperiodic and satisfies the Dirichlet conditions.

X(\Omega) = \int_{-\tau/2}^{\tau/2} A\,e^{-j\Omega t}\,dt = \frac{A}{-j\Omega}\Big[e^{-j\Omega\tau/2} - e^{j\Omega\tau/2}\Big] = \frac{2A\sin(\Omega\tau/2)}{\Omega}.

In hertz this becomes the famous sinc:

\boxed{X(F) = A\tau\,\frac{\sin(\pi F\tau)}{\pi F\tau} = A\tau\,\operatorname{sinc}(F\tau)}

Three things to say about it:

  • X(0) = A\tau, which is the area of the pulse.
  • The zeros are at F = \pm 1/\tau, \pm 2/\tau, \ldots, that is, at \Omega = \pm 2\pi/\tau, \pm 4\pi/\tau, \ldots
  • A wider pulse gives a narrower spectrum, and a narrower pulse a wider one. This is the time–bandwidth trade-off.

2b. What the transform means (note p.38–39)

X(\Omega) is a recipe. The inverse formula builds x(t) by adding up exponentials, and X(\Omega) says how much of each frequency goes in. If |X| has one tall peak, x(t) looks almost like a clean sinusoid at that frequency. If |X| is spread out, there is no single tone.

Duality. The forward and inverse formulas are nearly identical with t and \Omega swapped. So a rect transforms to a sinc and a sinc transforms to a rect, and convolution in one domain is multiplication in the other.

Phase carries most of the information. The magnitude says how much of each frequency there is. The phase says when each component peaks relative to the others. Keep the magnitude but scramble the phase, and every recognisable feature of the signal is gone. That is why a good filter tries to preserve phase relationships, and why linear-phase filters are popular: they delay every frequency by the same amount, so the shape survives.

3. The discrete-time Fourier series (periodic sequences)

A periodic sequence satisfies x[n] = x[n + N], and it is built from just N harmonics:

x[n] = \sum_{k=0}^{N-1} c_k\,e^{j2\pi kn/N}, \qquad c_k = \frac{1}{N}\sum_{n=0}^{N-1} x[n]\,e^{-j2\pi kn/N}.

The coefficients repeat, c_{k+N} = c_k, so only N of them are distinct. With sampling rate F_s, the index k = 0, \ldots, N-1 covers the frequencies F_k = kF_s/N, from 0 up to (but not including) F_s.

3a. Ex 4.2.1: determine the spectra

(a) x[n] = \cos(\sqrt2\,\pi n). Here \omega_0 = \sqrt2\,\pi, so f_0 = \omega_0/2\pi = 1/\sqrt2, which is irrational. A discrete-time sinusoid is periodic only when f_0 = k/N is a ratio of integers, so this signal is not periodic and has no DTFS. Its spectrum is a single frequency component at \omega = \pm\sqrt2\,\pi, which, brought back into [-\pi, \pi], sits at \pm(2 - \sqrt2)\pi.

(b) x[n] = \cos(\pi n/3). Now f_0 = 1/6, which is rational, so the period is N = 6. Expand with Euler's formula and match the terms with the DTFS sum:

\cos\frac{\pi n}{3} = \cos\frac{2\pi n}{6} = \tfrac12 e^{j2\pi n/6} + \tfrac12 e^{-j2\pi n/6}, \qquad\text{and}\qquad e^{-j2\pi n/6} = e^{j2\pi(5)n/6}.

So c_1 = c_5 = \tfrac12 and c_0 = c_2 = c_3 = c_4 = 0.

(c) x[n] = \{1, 1, 0, 0\}, repeated with N = 4. Only n = 0 and n = 1 contribute to the sum:

c_k = \tfrac14\big(1 + e^{-j\pi k/2}\big) \quad\Longrightarrow\quad c_0 = \tfrac12, \quad c_1 = \tfrac14(1 - j), \quad c_2 = 0, \quad c_3 = \tfrac14(1 + j).

3b. A periodic train of rectangular pulses (note p.43)

One period is x[n] = 1 for -N_1 \le n \le N_1 (that is 2N_1 + 1 ones) and 0 for the rest of the period. Then

c_k = \frac{1}{N}\sum_{n=-N_1}^{N_1} e^{-j2\pi kn/N}.

When k = 0, \pm N, \pm 2N, \ldots, every term is 1, so c_0 = (2N_1 + 1)/N. That is the average value, the DC level.

For every other k, it is a geometric sum. Write \alpha = 2\pi k/N and multiply the top and bottom by e^{j\alpha/2}; the result is a ratio of sines:

c_k = \frac{1}{N}\,\frac{\sin\big(\alpha(N_1 + \tfrac12)\big)}{\sin(\alpha/2)} = \frac{1}{N}\,\frac{\sin\big(2\pi k(N_1 + \tfrac12)/N\big)}{\sin(\pi k/N)}.

With N = 10 and N_1 = 2: c_0 = 0.5, c_1 = 0.3236, c_2 = 0, c_3 = -0.1236 and c_5 = 0.1, and an FFT agrees. This is the discrete cousin of the sinc.

3c. The power density spectrum of a periodic signal

The average power over one period can be computed from the coefficients. Substitute the synthesis formula for x^*[n] and swap the order of the two sums:

\begin{aligned} P_x &= \frac{1}{N}\sum_{n=0}^{N-1}|x[n]|^2 = \frac{1}{N}\sum_{n=0}^{N-1} x[n]\,x^*[n] = \frac{1}{N}\sum_{n=0}^{N-1} x[n]\sum_{k=0}^{N-1} c_k^*\,e^{-j2\pi kn/N} \\[6pt] &= \sum_{k=0}^{N-1} c_k^*\left[\frac{1}{N}\sum_{n=0}^{N-1} x[n]\,e^{-j2\pi kn/N}\right] = \sum_{k=0}^{N-1} c_k^*\,c_k. \end{aligned}
\boxed{P_x = \sum_{k=0}^{N-1}|c_k|^2}

The total power is the sum of the powers in the individual harmonics. A plot of |c_k|^2 against k is the power density spectrum. For a real x[n], c_k^* = c_{-k} = c_{N-k}, so |c_k| is symmetric and you only need k = 0, \ldots, N/2.

Check: the N = 10 pulse train has P_x = 5/10 = 0.5, and \sum_k |c_k|^2 = 0.5 as well.

4. The discrete-time Fourier transform (aperiodic sequences)

X(\omega) = \sum_{n=-\infty}^{\infty} x[n]\,e^{-j\omega n}, \qquad x[n] = \frac{1}{2\pi}\int_{2\pi} X(\omega)\,e^{j\omega n}\,d\omega.

Two facts to state whenever you use it:

  • It is always periodic with period 2\pi: X(\omega + 2\pi) = X(\omega), because e^{-j2\pi n} = 1 for every integer n.
  • It converges if x[n] is absolutely summable, \sum_n |x[n]| < \infty. The spectrum is then a continuous function of \omega.

4a. Final 2c: the DTFT of x[n] = a^n u[n] with |a| < 1

X(\omega) = \sum_{n=0}^{\infty}\big(ae^{-j\omega}\big)^n = \frac{1}{1 - ae^{-j\omega}},

which converges because |ae^{-j\omega}| = |a| < 1. Its squared magnitude is the energy density spectrum:

S_{xx}(\omega) = |X(\omega)|^2 = \frac{1}{(1 - ae^{-j\omega})(1 - ae^{j\omega})} = \frac{1}{1 - 2a\cos\omega + a^2}.

With a = 0.5, S_{xx}(0) = 4 and S_{xx}(\pi) = 0.444. The energy sits at low frequencies, so this is a low-pass signal. With a < 0 it flips and becomes high-pass.

4b. Final 2e: x[n] = a^n for 0 \le n \le M-1

The paper hints: use the time-shift property g[n - n_0] \leftrightarrow e^{-j\omega n_0}G(\omega).

Directly, it is a finite geometric series:

X(\omega) = \sum_{n=0}^{M-1}\big(ae^{-j\omega}\big)^n = \frac{1 - a^M e^{-j\omega M}}{1 - ae^{-j\omega}}.

The way the hint wants: write the finite sequence as an infinite one minus a shifted copy of itself,

x[n] = a^n u[n] - a^M\cdot a^{n-M}u[n-M],

and transform each piece, using the time-shift property on the second:

X(\omega) = \frac{1}{1 - ae^{-j\omega}} - a^M e^{-j\omega M}\,\frac{1}{1 - ae^{-j\omega}} = \frac{1 - a^M e^{-j\omega M}}{1 - ae^{-j\omega}}.

Same answer, and this route shows the examiner you used the property he asked for.

4c. A rectangular sequence (Proakis Ex 4.2.3): x[n] = A for 0 \le n \le L-1

Use the same factoring trick as for the moving average (Topic 1, Section 5):

X(\omega) = A\,\frac{1 - e^{-j\omega L}}{1 - e^{-j\omega}} = A\,e^{-j\omega(L-1)/2}\,\frac{\sin(\omega L/2)}{\sin(\omega/2)}.

Here |X(0)| = AL and the zeros are at \omega = 2\pi k/L. This is the discrete version of the sinc.

4d. The energy density spectrum and Parseval's relation

Write |x[n]|^2 = x[n]\,x^*[n], replace x^*[n] by its inverse-DTFT integral, and swap the sum and the integral:

\begin{aligned} E_x &= \sum_{n=-\infty}^{\infty}|x[n]|^2 = \sum_n x[n]\,x^*[n] = \sum_n x[n]\left[\frac{1}{2\pi}\int_{-\pi}^{\pi} X^*(\omega)\,e^{-j\omega n}\,d\omega\right] \\[6pt] &= \frac{1}{2\pi}\int_{-\pi}^{\pi} X^*(\omega)\left[\sum_n x[n]\,e^{-j\omega n}\right]d\omega = \frac{1}{2\pi}\int_{-\pi}^{\pi}|X(\omega)|^2\,d\omega. \end{aligned}
\boxed{E_x = \sum_{n=-\infty}^{\infty}|x[n]|^2 = \frac{1}{2\pi}\int_{-\pi}^{\pi}|X(\omega)|^2\,d\omega}

The function S_{xx}(\omega) = |X(\omega)|^2 is the energy density spectrum: it tells you how much of the energy sits in each small slice of frequency.

Final 2f (continuous-time Parseval). Find the energy of x_a(t) = e^{-\alpha t}u(t) with \alpha = 0.6.

In the time domain the integral is easy:

E = \int_0^{\infty} e^{-2\alpha t}\,dt = \frac{1}{2\alpha} = \frac{1}{1.2} = 0.8333 \text{ J}.

In the frequency domain, X(F) = \dfrac{1}{\alpha + j2\pi F}, so |X(F)|^2 = \dfrac{1}{\alpha^2 + 4\pi^2F^2}. Parseval says \int_{-\infty}^{\infty}|X(F)|^2\,dF gives the same 0.8333, and numerical integration agrees.

Final 1b. Find the energy and the power of x[n] = (-1)^n.

Every sample has |x[n]|^2 = 1, so the energy is E = \sum 1 = \infty and this is not an energy signal. The power is

P = \lim_{N\to\infty}\frac{1}{2N+1}\sum_{n=-N}^{N} 1 = 1,

so it is a power signal. Its spectrum sits entirely at \omega = \pi, the highest discrete-time frequency, because (-1)^n = \cos\pi n.

4e. Symmetry for real signals (note p.48, 51)

Split e^{-j\omega n} = \cos\omega n - j\sin\omega n to separate the real and imaginary parts:

X(\omega) = X_R(\omega) + jX_I(\omega), \qquad X_R(\omega) = \sum_n x[n]\cos\omega n, \qquad X_I(\omega) = -\sum_n x[n]\sin\omega n.

Cosine is even and sine is odd, so for a real x[n]

X_R(-\omega) = X_R(\omega)\ \ (\text{even}), \qquad X_I(-\omega) = -X_I(\omega)\ \ (\text{odd}), \qquad\text{hence}\qquad X(-\omega) = X^*(\omega).

This is called Hermitian symmetry. It means |X(\omega)| is even, \angle X(\omega) is odd, and S_{xx}(\omega) is even. So for a real signal you only need 0 \le \omega \le \pi (or 0 \le F \le F_s/2), which halves the work.

5. The Fourier transform and the z-transform (note p.49)

Take X(z) = \sum_n x[n]\,z^{-n} with ROC r_2 < |z| < r_1, and put z = re^{j\omega}:

X(z)\Big|_{z = re^{j\omega}} = \sum_n\big[x[n]\,r^{-n}\big]\,e^{-j\omega n}.

That is the DTFT of the weighted sequence x[n]\,r^{-n}. If the ROC contains the unit circle, set r = 1:

\boxed{X(\omega) = X(z)\Big|_{z = e^{j\omega}}}

The Fourier transform is the z-transform evaluated on the unit circle. If the ROC does not include the unit circle, as for 2^n u[n], the DTFT does not exist even though X(z) does.

6. Classifying signals by frequency content (note p.49)

Class Where the energy is Example
Low-frequency around \omega = 0 (F = 0) slowly varying waves, a DC level, an ECG
High-frequency near \omega = \pi (F = F_s/2) (-1)^n, sharp edges
Medium-frequency (band-pass) somewhere in between a radio station's signal

The bandwidth is F_2 - F_1, the range of frequencies that holds most of the energy (say 95%).

  • Narrowband: F_2 - F_1 \ll (F_1 + F_2)/2; the spectrum is a thin spike.
  • Wideband: the energy is spread over a broad range.
  • Bandlimited: X(F) = 0 for |F| > B. A signal cannot be both bandlimited and time-limited.

7. Properties of the DTFT (note p.50–53)

# Property x[n] X(\omega)
1 Linearity a_1x_1[n] + a_2x_2[n] a_1X_1(\omega) + a_2X_2(\omega)
2 Time shift x[n-k] e^{-j\omega k}X(\omega)
3 Frequency shift e^{j\omega_0 n}x[n] X(\omega - \omega_0)

7 Symmetry (real x) x[n] real X(-\omega) = X^*(\omega)
8 Periodicity any x[n] X(\omega + 2\pi) = X(\omega)

Notice what row 2 says: a time shift changes only the phase, never the magnitude.

The proofs to have ready, two lines each:

Time shift. Substitute m = n - k:

\sum_n x[n-k]\,e^{-j\omega n} = e^{-j\omega k}\sum_m x[m]\,e^{-j\omega m} = e^{-j\omega k}X(\omega).

Frequency shift. Combine the two exponentials:

\sum_n e^{j\omega_0 n}x[n]\,e^{-j\omega n} = \sum_n x[n]\,e^{-j(\omega - \omega_0)n} = X(\omega - \omega_0).

Modulation. Write \cos\omega_0 n = \tfrac12\big(e^{j\omega_0 n} + e^{-j\omega_0 n}\big) and apply the frequency shift twice.

Correlation. Substitute k = n - m in the inner sum:

S_{x_1x_2}(\omega) = \sum_m\sum_n x_1[n]\,x_2[n-m]\,e^{-j\omega m} = \sum_n x_1[n]\,e^{-j\omega n}\sum_k x_2[k]\,e^{j\omega k} = X_1(\omega)\,X_2(-\omega).

8. The properties from the missing slides (Proakis §4.4)

Time reversal. Substitute \ell = -n:

\sum_n x[-n]\,e^{-j\omega n} = \sum_\ell x[\ell]\,e^{-j(-\omega)\ell} = X(-\omega).

Wiener–Khintchine. Autocorrelation is row 6 with x_1 = x_2 = x, so S_{xx}(\omega) = X(\omega)\,X(-\omega) = X(\omega)\,X^*(\omega) = |X(\omega)|^2 for real x. In words: the autocorrelation and the energy density spectrum form a Fourier transform pair.

Windowing. Cutting a signal short (multiplying it by a window) convolves its spectrum with the window's spectrum. That is why truncation smears the spectrum and adds ripples, the Gibbs phenomenon.

Differentiation in frequency. Differentiate the DTFT term by term:

\frac{d}{d\omega}\sum_n x[n]\,e^{-j\omega n} = \sum_n(-jn)\,x[n]\,e^{-j\omega n} \quad\Longrightarrow\quad n\,x[n] \;\longleftrightarrow\; j\,\frac{dX(\omega)}{d\omega}.

0. The one formula

y(n) = x(n) * h(n) = \sum_{k=-\infty}^{\infty} x(k)\,h(n-k) = \sum_{k=-\infty}^{\infty} h(k)\,x(n-k).

The two forms are equal because convolution is commutative. Before any arithmetic, write down three facts; each one is a line of marks.

  1. Length. If x has N_1 samples and h has N_2, then y has N_1 + N_2 - 1 samples.
  2. Where it starts and ends. y starts at (start of x) + (start of h) and ends at (end of x) + (end of h).
  3. The useful range of k. Only those k for which both x(k) and h(n-k) can be nonzero contribute.

Method A: expand the sum (what sir marks)

A1. TT1 Question 4, done the expected way

Given.

x(n) = \{\underset{\uparrow}{1}, 2, 3, 1\}: \quad x(0) = 1,\ x(1) = 2,\ x(2) = 3,\ x(3) = 1,
h(n) = \{1, \underset{\uparrow}{2}, 1, -1\}: \quad h(-1) = 1,\ h(0) = 2,\ h(1) = 1,\ h(2) = -1.

Step 1: the ranges. x lives on 0 \le n \le 3 and h on -1 \le n \le 2, so y lives on 0 + (-1) \le n \le 3 + 2, that is -1 \le n \le 5. Its length is 4 + 4 - 1 = 7, which matches.

Step 2: write the sum over the range of x. Since x(k) \ne 0 only for k = 0, 1, 2, 3:

\begin{aligned} y(n) &= \sum_{k=0}^{3} x(k)\,h(n-k) = x(0)h(n) + x(1)h(n-1) + x(2)h(n-2) + x(3)h(n-3) \\[2pt] &= h(n) + 2h(n-1) + 3h(n-2) + h(n-3). \end{aligned}

Step 3: expand it for every n. Any h outside -1 \le n \le 2 is zero. Write those zeros out at least for the first few n, so that he can see you know where they come from:

\begin{aligned} y(-1) &= h(-1) + 2h(-2) + 3h(-3) + h(-4) = 1 + 0 + 0 + 0 = 1 \\ y(0) &= h(0) + 2h(-1) + 3h(-2) + h(-3) = 2 + 2(1) + 0 + 0 = 4 \\ y(1) &= h(1) + 2h(0) + 3h(-1) + h(-2) = 1 + 4 + 3 + 0 = 8 \\ y(2) &= h(2) + 2h(1) + 3h(0) + h(-1) = -1 + 2 + 6 + 1 = 8 \\ y(3) &= h(3) + 2h(2) + 3h(1) + h(0) = 0 - 2 + 3 + 2 = 3 \\ y(4) &= h(4) + 2h(3) + 3h(2) + h(1) = 0 + 0 - 3 + 1 = -2 \\ y(5) &= h(5) + 2h(4) + 3h(3) + h(2) = 0 + 0 + 0 - 1 = -1 \end{aligned}

and y(n) = 0 for n < -1 and for n > 5.

Step 4: box the answer, with the arrow.

\boxed{y(n) = \{1, \underset{\uparrow}{4}, 8, 8, 3, -2, -1\}}

Step 5: a one-line check. The sum of the output equals the product of the input sums: \sum y = 1 + 4 + 8 + 8 + 3 - 2 - 1 = 21, and \sum x \cdot \sum h = 7 \times 3 = 21. This check catches nearly every arithmetic slip, so always do it.

A2. Final 2021–22, Q1h

x(n) = \{-1, 3, 2, 0, 1\} on -2 \le n \le 2, and h(n) = \{-3, 5, 0, 1\} on -1 \le n \le 2.

The output lives on -3 \le n \le 4, with length 5 + 4 - 1 = 8. Since x(-2) = -1, x(-1) = 3, x(0) = 2, x(1) = 0 and x(2) = 1,

y(n) = \sum_{k=-2}^{2} x(k)\,h(n-k) = -h(n+2) + 3h(n+1) + 2h(n) + 0\cdot h(n-1) + h(n-2).

Expanding, with h(-1) = -3, h(0) = 5, h(1) = 0, h(2) = 1:

\begin{aligned} y(-3) &= -h(-1) = 3 \\ y(-2) &= -h(0) + 3h(-1) = -5 - 9 = -14 \\ y(-1) &= -h(1) + 3h(0) + 2h(-1) = 0 + 15 - 6 = 9 \\ y(0) &= -h(2) + 3h(1) + 2h(0) + h(-2) = -1 + 0 + 10 + 0 = 9 \\ y(1) &= 3h(2) + 2h(1) + h(-1) = 3 + 0 - 3 = 0 \\ y(2) &= 2h(2) + h(0) = 2 + 5 = 7 \\ y(3) &= h(1) = 0 \\ y(4) &= h(2) = 1 \end{aligned}
\boxed{y(n) = \{3, -14, 9, \underset{\uparrow}{9}, 0, 7, 0, 1\}}

Check: \sum y = 15 and \sum x \cdot \sum h = 5 \times 3 = 15.

A3. Infinite sequences: the same method, with a geometric series

x(n) = u(n) and h(n) = a^n u(n) with |a| < 1 (the Proakis Ex 2.3.3 type).

y(n) = \sum_k a^k\,u(k)\,u(n-k).

u(k) needs k \ge 0 and u(n-k) needs k \le n, so the sum runs over 0 \le k \le n, and only when n \ge 0:

y(n) = \sum_{k=0}^{n} a^k = \frac{1 - a^{n+1}}{1 - a}, \quad n \ge 0; \qquad y(n) = 0, \quad n < 0.

As n \to \infty, y(n) \to \dfrac{1}{1-a}. That is H(e^{j0}), the DC steady state from Topic 1 again.

x(n) = 2^n u(n) and h(n) = (0.5)^n u(n) (the "Imp for exam" one). The range is again 0 \le k \le n:

y(n) = \sum_{k=0}^{n} 2^k(0.5)^{n-k} = (0.5)^n\sum_{k=0}^{n} 4^k = \frac43\,2^n - \frac13\,(0.5)^n, \qquad n \ge 0.

See Q2 · z-Transform, Section 8b, for the z-transform version.

The three phrases that earn the method marks for infinite sums:

  • "u(k) \ne 0 requires k \ge 0."
  • "u(n-k) \ne 0 requires k \le n."
  • "Therefore, for n \ge 0 the sum runs over 0 \le k \le n, and for n < 0, y(n) = 0."

Method B: the z-transform (likely in Mid-2)

Convolution in time is multiplication in z:

Y(z) = X(z)\,H(z).

Multiply the two polynomials and read y(n) off as the coefficient of z^{-n}.

TT1 Question 4 again. x starts at n = 0, and the sample h(-1) = 1 gives a z^{1} term:

X(z) = 1 + 2z^{-1} + 3z^{-2} + z^{-3}, \qquad H(z) = z + 2 + z^{-1} - z^{-2}.

Multiply term by term and collect equal powers:

\begin{aligned} z^{1}: &\quad 1\cdot 1 = 1 \\ z^{0}: &\quad 1\cdot 2 + 2\cdot 1 = 4 \\ z^{-1}: &\quad 1\cdot 1 + 2\cdot 2 + 3\cdot 1 = 8 \\ z^{-2}: &\quad 1\cdot(-1) + 2\cdot 1 + 3\cdot 2 + 1\cdot 1 = 8 \\ z^{-3}: &\quad 2\cdot(-1) + 3\cdot 1 + 1\cdot 2 = 3 \\ z^{-4}: &\quad 3\cdot(-1) + 1\cdot 1 = -2 \\ z^{-5}: &\quad 1\cdot(-1) = -1 \end{aligned}
Y(z) = z + 4 + 8z^{-1} + 8z^{-2} + 3z^{-3} - 2z^{-4} - z^{-5} \quad\Longrightarrow\quad y(n) = \{1, \underset{\uparrow}{4}, 8, 8, 3, -2, -1\}.

The z^0 coefficient is the sample at n = 0. The ROC is all z except 0 and \infty, because the result is finite and two-sided.

For infinite signals, Method B means partial fractions; that is the 2^n and (0.5)^n example in Q2 · z-Transform, Section 8b.

Method D: graphical (fold, shift, multiply, add)

  1. Fold h(k) to get h(-k).
  2. Shift it by n to get h(n-k).
  3. Multiply x(k)\,h(n-k) point by point.
  4. Add the products over all k.

Each entry has up to four parts: the mistake people make under pressure, the picture, which is an intuition you can rebuild in the exam hall, the twist, which is how sir can change the same question, and a quick check that takes five seconds.

Sir's habit is to take a textbook example and change one thing: where the arrow is, the sign of a, the ROC, "for all n" versus "u[n]", or the method he demands. Before you start writing, circle whatever is different from the book.

All the new numbers here were checked with numpy (long division, the three-ROC inverse, the one-sided z-transform, the powers).

A. Convolution and sequences (where TT1 hurt)

A1. Where is n = 0? (the arrow)

The mistake. Treating the first number as n = 0 when the arrow is somewhere else.

The picture. The arrow is a "you are here" pin. Everything to its left is negative time.

The rule. The output starts at (start of x) + (start of h). In TT1, x starts at 0 and h at -1, so y starts at -1. The answer \{1, 4, 8, \ldots\} therefore has its arrow on the 4, not on the 1.

The twist. The same numbers with the arrow moved only shift the answer. The values do not change, so recompute just the start index.

Quick check. The length is N_1 + N_2 - 1, and \sum y = \sum x \cdot \sum h.

A2. x(-n + 2): fold first, or shift first?

The mistake. Shifting the wrong way (TT1 Q1 ii).

The picture. Forget about "operations". Ask where each sample lands. Set the argument equal to k: -n + 2 = k, so n = 2 - k. The sample x(k) moves to position 2 - k. So x(0) lands at n = 2, x(1) at n = 1, and x(-1) at n = 3.

In the language of operations: x(-n + 2) = x\big(-(n - 2)\big), so fold first, then shift the folded signal right by 2.

Quick check. Plug in one sample: the value of x(0) must end up at n = 2.

A3. Infinite convolution: getting the limits right

The mistake. Writing \sum_{k=-\infty}^{\infty} and getting stuck, or forgetting to say that y = 0 for n < 0.

The picture. u(k) is a gate that opens at k = 0, and u(n-k) is a gate that closes at k = n. You only add while both gates are open: 0 \le k \le n. If n < 0 the window is empty, so y(n) = 0.

The twist. Take h(n) = a^n u(n-2). The gate now opens at k = 2, so the sum runs over 2 \le k \le n, and y(n) = 0 for n < 2.

B. Topic 1: frequency response (Q1)

B1. "Steady state" when there is no transient

The mistake. Writing a transient for x[n] = A\cos(\omega_0 n), -\infty < n < \infty.

The picture. A transient is the system's surprise at the moment the input is switched on. If the input has been running forever (no u[n]), there is no switch-on moment and no surprise, so y[n] = y_{ss}[n] exactly. With u[n] there is a transient, and it dies away only if the system is stable.

The twist (final 5c). "x[n] = A\cos(\omega_0 n), -\infty < n < \infty." Answer y[n] = A\,|H(e^{j\omega_0})|\cos\big(\omega_0 n + \theta(\omega_0)\big) and stop there.

B2. \tan^{-1} lies about the quadrant

The mistake. For H = -1 - j, writing \tan^{-1}(1) = 45^\circ. The angle is actually -135^\circ.

The picture. Draw the point. A negative real part and a negative imaginary part put it in the bottom-left quadrant, so you must add or subtract 180^\circ.

The rule. If H_R < 0, then \theta = \tan^{-1}(H_I/H_R) \pm 180^\circ.

Quick check. From Section 3a of the T1 file, H(e^{j\pi/4}) = -1.586 - 2.071j has \theta = -127.4^\circ, not +52.6^\circ.

B3. A sine went in, so a sine comes out

The mistake. Writing cos in the answer when the input was \sin(\omega_0 n) (Mitra 4.68).

The picture. The system can only scale and delay, so it cannot turn a sine into a cosine. Whatever wave goes in comes out: y[n] = |H|\sin(\omega_0 n + \theta). If the input carries its own phase \phi, keep it: A\cos(\omega_0 n + \phi + \theta).

B4. Moving average with an even M

The mistake. Saying the delay is M/2, or ignoring the even-M case.

The picture. The output of a moving average is the average of a window, so it "belongs" to the centre of that window. The window covers n, n-1, \ldots, n-(M-1), whose centre is (M-1)/2 samples back. For M = 4 the delay is 1.5 samples. A half-sample delay is perfectly fine on paper.

Quick check. The zeros of |H| are at \omega = 2\pi k/M. For M = 4 they are at \pi/2 and \pi, so an even-M filter removes \omega = \pi exactly.

B5. Why the moving-average phase jumps

The mistake. Drawing the straight line -(M-1)\omega/2 all the way across.

The picture. H(e^{j\omega}) is a real function R(\omega) times e^{-j(M-1)\omega/2}. When R turns negative after a zero, "negative" means "multiplied by e^{j\pi}", so the phase gains \pi. It is not a mistake; it is just bookkeeping for the sign.

Write: \theta(\omega) = -\dfrac{(M-1)\omega}{2} + \pi\times(\text{number of zeros below } \omega).

B6. If a system creates new frequencies, it is not LTI

The picture. An LTI system is a set of volume knobs, one per frequency. The knobs can turn a frequency up, down or off, but they can never add one. Squaring, multiplying by a cosine and down-sampling (x[4n]) all add frequencies, so none of them is LTI (Mitra 4.60).

The twist. "Is y[n] = x^2[n] characterised by a frequency response?" No. It is not LTI, so H(e^{j\omega}) has no meaning for it.

B7. A frequency above \pi is a lower frequency in disguise

The mistake. Treating \cos(1.5\pi n) as a high-frequency signal.

The picture. A discrete-time frequency lives on a circle. 1.5\pi lands on the same spot as 1.5\pi - 2\pi = -0.5\pi, so \cos(1.5\pi n) = \cos(0.5\pi n).

Quick check. Always reduce \omega into (-\pi, \pi] before reading off |H|. The highest discrete-time frequency is \pi, which is (-1)^n.

B8. The eigenfunction trick (4.54)

z^n for all n is an eigenfunction. z^n u[n] is not: switching on at n = 0 adds a transient, so the output is not exactly H times the input. It is the same idea as B1.

C. Topic 2: the z-transform (Q2)

C1. Which side the ROC is on, in one sentence

The picture. z^{-n} with a large |z| crushes the right-hand side (n \to +\infty) and blows up the left-hand side. So the right-sided part needs |z| large (outside a circle) and the left-sided part needs |z| small (inside a circle). A two-sided signal needs both, which gives a ring.

Quick check. The ROC is bounded by poles and never contains one.

C2. H(z) given without an ROC: three different answers

H(z) = \frac{1}{(1 - 0.5z^{-1})(1 - 2z^{-1})} = \frac{-1/3}{1 - 0.5z^{-1}} + \frac{4/3}{1 - 2z^{-1}}
ROC h[n] Causal? Stable?
\lvert z\rvert > 2 -\frac13(0.5)^n u[n] + \frac43\,2^n u[n] yes no (2^n blows up)
0.5 < \lvert z\rvert < 2 -\frac13(0.5)^n u[n] - \frac43\,2^n u[-n-1] no yes (contains \lvert z\rvert = 1)
\lvert z\rvert < 0.5 \frac13(0.5)^n u[-n-1] - \frac43\,2^n u[-n-1] anti-causal no

Check: summing the ring version at z = 1 gives H(1) = -2.

If he asks for "the h[n] that makes the system stable", pick the ROC that contains the unit circle, which is the ring. If he says "causal", take the region outside the largest pole. If he gives neither an ROC nor a condition, list all three; he will love it.

The rule for each term: if the ROC lies outside the pole p (|z| > |p|), that term gives p^n u[n]; if the ROC lies inside it (|z| < |p|), the term gives -p^n u[-n-1].

C3. Partial fractions: divide by z first

The mistake. Doing partial fractions on X(z) directly and ending up with a stray constant or the wrong shape.

The picture. The table entry is \dfrac{z}{z - p} \leftrightarrow p^n u[n]. Dividing by z first guarantees that every term comes back in the form \dfrac{z}{z-p} when you multiply by z again.

The improper case. If the numerator's degree (in powers of z^{-1}) is at least the denominator's, divide the polynomials first; the quotient gives \delta terms. The X(z)/z trick handles the "equal degree" case automatically.

C4. Repeated poles: don't drop a term

A double pole at p needs two terms, \dfrac{B}{z - p} + \dfrac{C}{(z - p)^2}. The second one becomes n\,p^n u[n], through the pair n a^n u[n] \leftrightarrow \dfrac{az^{-1}}{(1 - az^{-1})^2}; watch out for the extra factor of a.

Quick check. For a causal signal, x[0] = \lim_{z\to\infty} X(z) (the initial value theorem). In Section 8c of the T2 file, X(\infty) = 1, and indeed \frac49 + \frac59 + 0 = 1.

C5. The sign inside (1 + 2z^{-1})

\frac{1}{1 + 2z^{-1}} = \frac{1}{1 - (-2)z^{-1}} \;\longleftrightarrow\; (-2)^n u[n].

The pole is at z = -2. Your note slipped at exactly this point.

Quick check. Find the pole by setting the bracket to zero: 1 + 2z^{-1} = 0 gives z = -2.

C6. Shifted and flipped versions sir can swap in

x[n] X(z) ROC
a^n u[n-1] \dfrac{az^{-1}}{1 - az^{-1}} \lvert z\rvert > \lvert a\rvert
a^{n-1}u[n-1] \dfrac{z^{-1}}{1 - az^{-1}} \lvert z\rvert > \lvert a\rvert
u[-n] \dfrac{1}{1 - z} \lvert z\rvert < 1
a^{\lvert n\rvert} with \lvert a\rvert < 1 \dfrac{1}{1 - az^{-1}} + \dfrac{az}{1 - az} \lvert a\rvert < \lvert z\rvert < 1/\lvert a\rvert
(n+1)\,a^n u[n] \dfrac{1}{(1 - az^{-1})^2} \lvert z\rvert > \lvert a\rvert

The method for any of these: write it as a known pair, then apply a shift (multiply by z^{-k}), scaling (a^n replaces z by z/a), or reversal (z \to 1/z, which flips the ROC).

C7. The inverse by long division (Proakis Ex 3.4.x)

X(z) = \frac{1}{1 - 1.5z^{-1} + 0.5z^{-2}}

With ROC |z| > 1 (causal), divide in ascending powers of z^{-1}:

X(z) = 1 + 1.5z^{-1} + 1.75z^{-2} + 1.875z^{-3} + \cdots \quad\Longrightarrow\quad x[n] = \{\underset{\uparrow}{1}, 1.5, 1.75, 1.875, 1.9375, \ldots\}.

With ROC |z| < 0.5 (anti-causal), write the denominator in ascending powers of z, as 0.5z^{-2} - 1.5z^{-1} + 1, and divide:

X(z) = 2z^2 + 6z^3 + 14z^4 + 30z^5 + \cdots \quad\Longrightarrow\quad x[n] = \{\ldots, 30, 14, 6, 2, 0, \underset{\uparrow}{0}\}.

The picture. Causal means the series must run towards z^{-1} (future samples); anti-causal means it must run towards z (past samples). The ROC tells you which way to divide.

Long division gives numbers, not a closed form. Use it when he says "the first few samples", or when the poles are ugly.

Quick check. The closed form for the causal case is x[n] = 2 - (0.5)^n, which gives 1, 1.5, 1.75.

C8. A difference equation with initial conditions (one-sided z-transform, Proakis 3.6)

The mistake. Using the two-sided shift z^{-1}Y(z) when y(-1) \ne 0.

The rule (one-sided z-transform).

\mathcal{Z}^+\{y(n-1)\} = z^{-1}Y^+(z) + y(-1), \qquad \mathcal{Z}^+\{y(n-2)\} = z^{-2}Y^+(z) + z^{-1}y(-1) + y(-2).

Example. y(n) = 0.5\,y(n-1) + x(n) with x(n) = u(n) and y(-1) = 1.

\begin{aligned} Y &= 0.5\big[z^{-1}Y + 1\big] + \frac{1}{1 - z^{-1}} \quad\Longrightarrow\quad Y\big(1 - 0.5z^{-1}\big) = 0.5 + \frac{1}{1 - z^{-1}}, \\[6pt] Y &= \frac{0.5}{1 - 0.5z^{-1}} + \frac{1}{(1 - 0.5z^{-1})(1 - z^{-1})} = \frac{0.5}{1 - 0.5z^{-1}} + \frac{2}{1 - z^{-1}} - \frac{1}{1 - 0.5z^{-1}}. \end{aligned}
\boxed{y(n) = 2 - (0.5)^{n+1}, \qquad n \ge 0}

The poles of Y^+(z) are at 0.5 and 1, and a one-sided transform is always right-sided, so ROC: |z| > 1.

Quick check. By recursion, y(0) = 0.5\cdot 1 + 1 = 1.5 and y(1) = 0.5\cdot 1.5 + 1 = 1.75. The formula gives 1.5 and 1.75.

The picture. The initial condition is energy already stored in the system. It shows up as an extra term that decays away (the zero-input response); the rest is the zero-state response.

C9. Stability and causality are separate questions

Causal means the ROC is outside the outermost pole (and includes \infty). Stable means the ROC contains |z| = 1. "Poles inside the unit circle means stable" is true only for causal systems, so say "causal and stable if and only if all poles are inside the unit circle".

C10. Counting poles and zeros at the origin

Convert to positive powers of z before you count. \dfrac{1}{1 - az^{-1}} = \dfrac{z}{z - a} has a zero at z = 0, and people forget to draw it. In final 6b, the (M-1)-fold pole at the origin carries the marks, so label it "(M-1)".

D. Topic 3: frequency analysis (Q3)

D1. Is a discrete-time sinusoid periodic?

The mistake. "Cosine is periodic, so of course it is."

The picture. A discrete-time sinusoid repeats only if, after N steps, it has turned through a whole number of full circles: \omega_0 N = 2\pi k. That means f_0 = \omega_0/2\pi = k/N must be rational.

  • \cos(\pi n/3): f_0 = 1/6, so N = 6.
  • \cos(\sqrt2\,\pi n): f_0 = 1/\sqrt2 is irrational, so it is not periodic.
  • \cos(n/6): f_0 = 1/(12\pi) is irrational, so it is not periodic, even though \cos(t/6) in continuous time is. A favourite trick.
  • \cos(\pi n/3) + \cos(\pi n/4): N_1 = 6 and N_2 = 8, so N = \operatorname{lcm}(6, 8) = 24.
  • Final 1d, \sin(5\pi n) and \sqrt3\cos(5\pi n): f_0 = 5/2 gives N = 2 for both, so the common period is 2.

D2. Energy signal or power signal?

x[n] Energy Power Type
a^n u[n], \lvert a\rvert < 1 \frac{1}{1 - a^2} (= 1.333 for a = 0.5) 0 energy
u[n] \infty \frac12 (not 1) power
(-1)^n; A\cos(\omega_0 n) \infty 1; \frac{A^2}{2} power
n\,u[n] \infty \infty neither

The picture. Power is an average over a window from -N to N. u[n] is "on" for only half of that window, so P = \frac12.

Quick check. Finite energy means zero power. Finite, nonzero power means infinite energy.

D3. Where the 2\pi goes in Parseval

  • Discrete time, aperiodic: \displaystyle\sum_n |x[n]|^2 = \frac{1}{2\pi}\int_{-\pi}^{\pi}|X(\omega)|^2\,d\omega.
  • Discrete time, periodic: \displaystyle\frac{1}{N}\sum_{n=0}^{N-1}|x[n]|^2 = \sum_{k=0}^{N-1}|c_k|^2, with no 2\pi.
  • Continuous time in hertz: \displaystyle\int|x(t)|^2\,dt = \int|X(F)|^2\,dF, with no 2\pi. In \Omega it becomes \frac{1}{2\pi}\int|X(\Omega)|^2\,d\Omega.

The picture. A 2\pi appears whenever the frequency variable is in radians, because one full turn costs 2\pi radians. In hertz it does not.

D4. How many coefficients: CTFS versus DTFS

The CTFS has infinitely many c_k (k from -\infty to \infty). The DTFS has only N distinct ones (k = 0, \ldots, N-1), because c_{k+N} = c_k.

The picture. A discrete-time signal cannot wiggle faster than (-1)^n, so only N different "speeds" are available.

The twist. "Find c_7 for N = 6." Since c_7 = c_1, just give c_1.

D5. A DTFT that does not exist

2^n u[n] (it grows) and u[n] (its pole is on the unit circle) have no ordinary DTFT. The reason to write: they are not absolutely summable; equivalently, the ROC does not include |z| = 1. Their z-transforms do exist. Use this sentence whenever he asks you to "use the frequency domain" on a growing signal.

D6. Square-wave variants

  • The \pm 1 even square wave: c_0 = 0 and c_k = \frac{2}{k\pi}\sin\frac{k\pi}{2}.
  • The 0/1 square wave with the same timing equals \frac12(\text{the } \pm 1 \text{ version} + 1), so c_0 = \frac12 and c_k = \frac{1}{k\pi}\sin\frac{k\pi}{2}.
  • Shifted by T_0/4 (odd symmetry instead of even): the magnitudes stay the same and only the phases change. That is the time-shift property from Section 7 of the T3 file.

The picture. Shifting in time never changes how much of each harmonic there is, only when it peaks.

D7. A wider pulse has a narrower spectrum

A rect of width \tau has its first zero at F = 1/\tau. Double \tau and the spectrum halves in width while its peak height A\tau doubles. If he asks "what happens to the spectrum if the pulse gets wider?", that is the answer, with this picture: long in time means narrow in frequency.
