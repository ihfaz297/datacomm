Convolution by expansion

x(n) = {1↑, 2, 3, 1}, h(n) = {1, 2↑, 1, −1}. Step through n. Top row: x(k). Bottom row: h(n−k), which is h folded and shifted to n. Red stems overlap, and their products add up to y(n).

Write this: ranges first (y on −1…5, length 4+4−1 = 7), then y(n) = h(n)+2h(n−1)+3h(n−2)+h(n−3) expanded for every n. Check: Σy = Σx·Σh = 21.

Q1 · Mitra 4.8.4

Moving-average filter

|H(ejω)| = |sin(Mω/2) / (M sin(ω/2))|. Zeros at ω = 2πk/M. The phase is −(M−1)ω/2 and jumps by π at each zero, because the real factor changes sign there.

|H|phase θ(ω) / π

Write this: |H(0)| = 1 and the gain falls toward ω = π, so it is a low-pass filter. Linear phase means a delay of (M−1)/2 samples.

Q1 · Mitra 4.8.5 · 4.8.6 · 4.68

Transient dies, steady state stays

h[n] = aⁿu[n], input sin(ω₀n)u[n] switched on at n = 0. Blue stems are the true output y[n]. The grey curve is yss = |H| sin(ω₀n + θ). Red bars are the difference y − yss, the transient. They shrink like aⁿ.

y[n]yss[n]ytr[n]

Write this: y[n] = H(ejω)ejωn − ejωnΣk=n+1∞h[k]e−jωk. The second term → 0 because the system is stable (|a| < 1).

Q2 · Proakis 3.1.3 · 3.1.5 · final 6a

Where the ROC lives

Shaded = ROC. × = pole, ○ = zero, dashed = unit circle. The formula is the same for causal and anti-causal. Only the ROC tells them apart.

Write this: right-sided → outside a circle, left-sided → inside, two-sided → ring |a| < |z| < |b|. If |b| ≤ |a| there is no overlap, so X(z) does not exist. Stable ⇔ the ROC contains |z| = 1.

Q2 · final 6b

Pole-zero plot of aⁿ, 0 ≤ n ≤ M−1

X(z) = (zM − aM) / (zM−1(z − a)). The M zeros sit evenly on the circle of radius a. The one at z = a is cancelled by the pole at z = a, which leaves M−1 zeros and M−1 poles at the origin.

Write this: zeros zk = a·ej2πk/M, k = 1…M−1; an (M−1)-order pole at z = 0; ROC |z| > 0.

Q3 · Proakis 4.1 · note p.35–37

Building a square wave from harmonics

ck = (2/kπ) sin(kπ/2). Even harmonics are zero, and the odd ones shrink like 1/k. Add more harmonics and the sum hugs the square. The overshoot at the jumps never goes away (Gibbs).

Write this: x(t) even ⇒ sine terms integrate to 0. c₀ = 0, ceven = 0, codd = ±2/(kπ). Only odd harmonics survive, decaying as 1/k.
