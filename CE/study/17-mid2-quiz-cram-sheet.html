Guess rules read twice

10 min · when you blank, these pick the answer

  • Amplitude → ASK / AM. Frequency → FSK / FM. Phase → PSK / PM. Amplitude + phase → QAM.The first letter tells you what changes: A, F, P. QAM mixes two of them.
  • Light, glass, cladding, "high bandwidth of fiber" → fiber-optic / WDM.
  • Analog multiplexing → FDM. Digital → TDM. Light → WDM.
  • Noise question: the amplitude-based one suffers most → ASK. Twist / shield / outer conductor are what reduce noise.Noise is a spike in height, so whatever stores data in height gets hurt.
  • How many phases? Anything "connection" (circuit, virtual-circuit) → 3 (setup, data, teardown). Datagram → 1.
  • Independent / different routes / out of order → datagram. Same path / VCI → virtual-circuit. Dedicated / reserved / telephone → circuit switching.
  • Detect s errors → dmin = s+1. Correct t errors → 2t+1.Detect 5 → 6. Correct 5 → 11.
  • Checksum, CRC, parity → detect only. Correct → Hamming code / FEC.
  • Bit-oriented → HDLC, bit stuffing. Byte-oriented → PPP, ESC byte.Alphabetical: HDLC comes before PPP, and bit before byte.
  • ACK number = the next frame expected. Got frame 0 → ACK 1.
  • Bits per symbol = log2(levels): 2→1, 4→2, 8→3, 16→4, 32→5, 64→6, 128→7, 256→8.
  • Statistical TDM = smart: only active inputs get slots, so each slot needs an address. Synchronous = fixed: idle inputs still get slots (wasted).
  • Spread spectrum wastes bandwidth on purpose → privacy / anti-jamming. Hops → FHSS. Chips / code / n bits per bit → DSSS.
  • "Which is NOT guided?" → air / atmosphere. Guided = any cable.
  • No idea at all? On "how many" questions, the middle number (two or three) is the safest guess. On "which layer", circuit = physical is the classic.

Formulas all of them

15 min · formula, then when to use it, then one worked example in grey

Ch 5 · Analog transmission

  • r = log₂ L · L = 2^r → bits per signal element from the number of levels (amplitudes, frequencies, phases, dots).FSK with 8 frequencies → 3. QAM with 128 points → 7.
  • S = N / r · N = S × r → baud rate from bit rate.8000 bps, 1000 baud → r = 8, L = 256. 4 bits/element × 1000 baud → 4000 bps.
  • B = (1 + d) S → bandwidth for ASK, PSK, QAM (d is between 0 and 1). d = 0 → B = S. d = 1 → B = 2S.QPSK at 12 Mbps, d = 0: S = 6 Mbaud, B = 6 MHz.
  • B = (1 + d) S + 2Δf → BFSK (2Δf is the gap between the two frequencies).
  • B = L × S → MFSK with d = 0.2 bits at a time, 4 Mbps: L = 4, S = 2 Mbaud, B = 8 MHz.
  • fc = (f_low + f_high) / 2 → carrier frequency is the middle of the band.200–300 kHz, ASK, d = 1: fc = 250 kHz, S = 100k / 2 = 50 kbaud = 50 kbps.
  • B_AM = 2B · B_FM = 2(1 + β)B (β ≈ 4) · B_PM = 2(1 + β)B5 kHz audio → 10 kHz AM station. 15 kHz audio, β = 4 → 150 kHz (FM station allocated 200 kHz).
  • A = √(I² + Q²) · phase = tan⁻¹(Q / I) → peak amplitude and phase of a constellation point.Point (−1, 1) → A = √2 ≈ 1.41, phase 135°.

Ch 6 · Multiplexing

  • B = n·Bc + (n − 1)·Bg → FDM total bandwidth (guard bands only between channels).5 × 100 kHz, 10 kHz guard: 500 + 40 = 540 kHz. 3 × 4 kHz, 500 Hz guard: 13 kHz.
  • Synchronous TDM, n inputs at R bps, 1 unit per slot: link rate = n × R · output bit = 1 / link rate · frame duration = input bit duration · frame rate = R / unit4 × 1 Mbps: input bit 1 µs, link 4 Mbps, output bit 0.25 µs, frame 1 µs, 1,000,000 frames/s.
  • bits per frame = n × u + framing bits · link rate = frame rate × bits per frame
  • T-1 = (24 × 8 + 1) × 8000 = 1.544 Mbps · frame = 1/8000 = 125 µs
  • B_ss = n × B → DSSS with n chips per bit (Barker n = 11). FHSS uses M = 2^k hop frequencies.

Ch 7 · Media

  • dB = 10 log₁₀(P₂ / P₁) → gain or loss. Half the power → −3 dB, a tenth → −10 dB. Total dB = add them up.
  • propagation time = distance / speed (cable ≈ 2 × 10⁸ m/s, air ≈ 3 × 10⁸ m/s)1 km of cable: 1000 / 2×10⁸ = 5 µs.

Ch 8 · Switching

  • crossbar = n × m crosspoints (N × N → N²)100 × 100 → 10,000.
  • 3-stage total = 2kN + k(N/n)² → stage 1: N/n crossbars of n × k. Middle: k crossbars of (N/n) × (N/n). Stage 3: N/n crossbars of k × n.N = 100, 10 crossbars (n = 10), k = 4 → 800 + 400 = 1200.
  • max connections = k × (N/n) · blocking factor = that / N4 × 10 = 40 → 40/100 = 0.4.
  • Clos: n = √(N/2) · k = 2n − 1 · total ≥ 4N(√(2N) − 1)N = 200 → n = 10, k = 19, 15,200 crosspoints.
  • datagram delay = 3T + 3τ + w₁ + w₂ · VC delay = 3T + 3τ + setup + teardown (2 switches, 3 links)
  • Banyan stages = log₂ N

Ch 10 · Errors

  • d(x, y) = number of 1s in x XOR y10101 vs 11110 → 01011 → 3.
  • detect s: d_min = s + 1 · correct t: d_min = 2t + 1d_min = 5 → detects 4, corrects 2.
  • bits hit by a burst = noise duration × bit rate1/100 s noise at 1 kbps → 10 bits. At 1 Mbps → 10,000 bits.
  • Block code: r = n − k · unused codewords = 2ⁿ − 2ᵏ4B/5B: 32 − 16 = 16 unused.
  • CRC: zeros to append = divisor bits − 1 · codeword = data + remainder1001 ÷ 1011: dividend 1001000, remainder 110, codeword 1001110.
  • Hamming code: 2^r ≥ m + r + 17 data bits → r = 4 → 11-bit codeword.
  • Checksum: add, wrap the carry back in, complement.4-bit: 7+11+12+0+6 = 36 → 0100 + 10 = 6 → complement → 9.
  • Polynomial: bits = degree + 1 · terms = number of 1s · shift left m = × x^m

Ch 11 · Data link control

  • bandwidth-delay product = bandwidth × RTT → bits that fit "in the pipe".1 Mbps × 20 ms = 20,000 bits. 10 Mbps × 2 ms = 20,000 bits.
  • Stop-and-Wait utilization = frame bits / (bandwidth × RTT)1000 / 20,000 = 5%.
  • Window with m-bit sequence numbers: Stop-and-Wait: mod 2 · Go-Back-N ≤ 2^m − 1 · Selective Repeat ≤ 2^(m−1)m = 3 → GBN 7, SR 4.

CH 07 Transmission Media new to you

The split

  • Guided (a cable) → twisted-pair, coaxial, fiber. Unguided (wireless, air) → radio, microwave, infrared.
  • Media sit below the physical layer.

  • Why twist? → reduce noise / crosstalk.Both wires pick up the same noise, and the receiver subtracts one from the other, so it cancels.
  • UTP vs STP → STP has a metal shield. UTP = unshielded, cheap, common.
  • Coax build → inner copper core, insulator, outer conductor (shield), plastic cover.

Fiber

  • Core is denser than cladding. Light hits the edge above the critical angle → reflects and stays inside.Below the critical angle it refracts (leaks out). At exactly critical it bends along the edge. Above it, it reflects. Fiber works on reflection.
  • Modes: multimode step-index (worst distortion), multimode graded-index (middle), single-mode (best: thinnest core, longest distance).
  • Advantages → higher bandwidth, less attenuation, immune to electromagnetic noise, light weight, no corrosion, hard to tap.
  • Disadvantages → needs skilled installation, one-way (two fibers for two-way), cost.

  • Three switching methods → circuit, packet, message. Message switching → application layer (store and forward).
  • Packet switching → 2 kinds (datagram + virtual-circuit), used at data-link + network layers.
  • 3 phases → setup, data transfer, teardown.Like a phone call: dial, talk, hang up. A datagram is a postcard: just send it.

Switch hardware

  • Crossbar n × m → n·m crosspoints. Never blocks, but too many crosspoints and fewer than 25% are used at once.
  • Multistage → fewer crosspoints, but blocking.
  • 3-stage crosspoints 2kN + k(N/n)². Classic: N = 100, n = 10, k = 4 → 1200, max 40 connections, blocking factor 0.4.
  • Clos (non-blocking) → n = √(N/2), k = 2n − 1.
  • Time-division switch → TSI (time-slot interchange, uses RAM). TST = time-space-time.
  • Banyan → log2N stages (8 inputs → 3).

CH 11 Data Link Control new to you

20 min

  • DLC does → framing + flow control + error control (node to node).
  • Flow control = don't drown the receiver. Error control = CRC; a bad frame is silently dropped and resent later.
  • Fixed-size frames (ATM) → no flags needed. Variable-size → need flags to mark start and end.
  • Flag = 01111110 (a 0, six 1s, a 0).
  • Byte stuffing → add an ESC byte before any flag or ESC inside the data.
  • Bit stuffing → after five 1s, add a 0. So 01111110 becomes 011111010.Six 1s in a row would look like a flag, so we break it at five.

Stop-and-Wait

  • Send one frame, keep a copy, start a timer, wait for the ACK.
  • Sequence numbers → 0 and 1 only (modulo 2).
  • ACK = next expected. Frame 0 → ACK 1. Frame 1 → ACK 0.
  • Frame lost or ACK lost → timer expires → resend the same frame. The receiver throws away the duplicate and ACKs again.
  • Corrupted frame → silently discarded (no NAK). The timer saves it.
  • Piggybacking → the ACK rides inside a data frame going back.
  • Noisy channel protocols → 3: Stop-and-Wait ARQ, Go-Back-N, Selective Repeat. Noiseless → 2: Simplest, Stop-and-Wait.
  • ACK 3 = got everything up to 2, send 3. NAK 3 = frame 3 was bad, resend it.

  • HDLC frames: I = information (user data) · S = supervisory (ACK/flow only, the shortest) · U = unnumbered (link management).I = Info, S = Supervise, U = Unnumbered, used for setup and teardown.
  • HDLC address field → address of the secondary station. Flag → marks the start and end. FCS → error check (CRC). P/F bit → present in every control field.
  • PPP address 11111111 = broadcast. It defines no sender or receiver, so the answer is "None". Control 00000011 is like an HDLC U-frame.
  • PPP protocol field → what's inside the payload. FCS → error control.
  • PPP phases: Dead → Establish (options negotiated, LCP) → Authenticate (identity checked) → Network (NCP) → Open → Terminate → Dead."Do Each Agent's Network Opening, Then Die."
  • LCP purpose → all of them: configuration, termination, option negotiation.
  • PAP → 2 steps, sends the password in plain text. CHAP → 3 steps: challenge value + own password → result. The password is never sent.

CH 05 Analog Transmission

8 min · you've done this, skim it

  • ASK, FSK, PSK, QAM → digital-to-analog. AM, FM, PM → analog-to-analog. "Not analog-to-analog" → QAM.
  • Carriers: BASK 1, BPSK 1, BFSK 2. QAM uses two carriers: in-phase + quadrature.
  • Baud vs bit rate → baud ≤ bit rate (S = N / r).
  • ASK bandwidth B = (1+d)S → "equal to or greater than the signal rate". FSK is wider than ASK.
  • Carrier frequency → middle of the band (200–300 kHz → 250 kHz).
  • Constellation: distance from centre = amplitude, angle = phase, number of dots = levels.
  • AM bandwidth = 2 × audio. AM station 10 kHz · FM station 200 kHz.
  • 8000 bps, 1000 baud → 8 bits per element, 2⁸ = 256 levels.

CH 06 Bandwidth Utilization

8 min

  • Multiplexing = many signals share one link at the same time.
  • "Shifts each signal to a different carrier" → FDM. Light beams → WDM. "Digital process sharing a link" → TDM.
  • TDM types → synchronous and statistical.
  • Groups, supergroups, master, jumbo → FDM.
  • Multilevel, multiple-slot, pulse stuffing, frame synchronization → all TDM.Slots, frames, pulses, levels: those are time words, so TDM.
  • Pulse stuffing = add dummy bits so unequal rates fit. Multiple-slot = the fast line gets more slots. Multilevel = combine in stages.
  • FDM bandwidth = channels + guard bands between them: 5 × 100 + 4 × 10 = 540 kHz.
  • T-1 → 8000 frames/s, 24 channels, 193 bits per frame, 1.544 Mbps.
  • FHSS = M carrier frequencies, hops between them. DSSS = each bit replaced by n bits (a spreading code).

CH 10 Error Detection

8 min

  • Single-bit error = one bit per data unit flipped. Burst = 2 or more bits.
  • ASCII letter swap (G→D, H→L): compare the bits. 1 bit differs → single-bit. More → burst. G→D = burst, H→L = single-bit.
  • One's complement → checksum. Polynomials → CRC. One redundant bit → simple parity.
  • Simple parity detects only an odd number of errors.
  • CRC check bits = the remainder. The quotient is discarded. Nonzero remainder at the receiver = damaged.
  • CRC dividend = data + (divisor length − 1) zeros. 111111 with 1010 → 111111000. Codeword = data + remainder: 111111 + 110 = 111111110.
  • Remainder of r bits → divisor of r+1 bits. CRC-8 → 9 bits.
  • Polynomial terms = number of 1s. 10 bits with four 0s → 6 terms.
  • Checksum at receiver: sum = all 1s (−0), complement = 0 → no error.
  • Hamming distance = count the positions that differ.
