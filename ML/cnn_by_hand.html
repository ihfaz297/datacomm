Start here

The picture: a stencil sliding over the image

  1. A kernel is a small stencil of weightsFor example a 3×3 grid of 9 numbers. It describes one small pattern, like a vertical edge.The network learns these 9 numbers, just like weights in an MLP.
  2. Slide it over the imageAt each spot, multiply every cell of the stencil by the pixel under it and add them up.One number per spot: "how much does this patch look like my pattern?"
  3. The grid of answers is a feature mapIt's a map of where the pattern shows up in the image.10 kernels give 10 feature maps, stacked as the depth of the output.
  4. The same stencil is used everywhereThis is weight sharing. An "ear detector" learned in one corner finds ears anywhere.That's translation invariance, and it's why CNNs need so few weights.
  5. Max pooling shrinks the mapEach 2×2 block is replaced by its biggest value."Was the pattern somewhere around here?" Yes or no, and not exactly where.
  6. Stack layers into a hierarchyEarly layers find edges, later ones combine edges into textures, then parts, then objects.At the end: flatten, a dense layer or two, then softmax over the classes.

The number that makes the point: on a 28×28 image, a dense layer of 64 neurons needs 784 × 64 + 64 = 50,240 parameters. A conv layer with 64 filters of 3×3 needs (3×3×1 + 1) × 64 = 640.

C1

The key characteristic that beats a dense layer

F2024a Q6c-i

A dense layer connects every pixel to every neuron. What does a conv layer look at instead, and what does that buy you?

Show the answer

Dense layers learn global patterns, which involve all the pixels at once. Convolution layers learn local patterns: small windows such as 3×3, with the same weights reused at every position. That one characteristic gives CNNs two properties:

  1. Translation invariance. A pattern learned in one place (say, an edge in the bottom-right corner) is recognised anywhere in the image. A dense layer would have to learn it again for every position. So a CNN needs far fewer training images.
  2. Spatial hierarchy. The first layers learn small patterns like edges. The next layers combine them into textures and parts, and later layers into whole objects. Images are built this way, so CNNs fit them well.

Bonus line: weight sharing also means far fewer parameters, 640 vs 50,240 in the example above.

The question's wording comes from Chollet, Deep Learning with Python, which gives exactly these two properties.

C2

Why CNN suits image classification

F2022 Q4b

What does a dense layer throw away when it flattens an image? What does a CNN keep?

Show the answer
  • It keeps the 2-D structure. A dense layer flattens the image into a long vector and loses which pixels are neighbours. Convolution works on neighbourhoods directly.
  • Local patterns with shared weights. The same filter scans the whole image, so a feature is found wherever it appears (translation invariance), with far fewer parameters, which means less overfitting and less data needed.
  • A hierarchy of features. Edges, then textures, then parts, then objects, the way images are actually built.
  • Pooling. It shrinks the feature maps, cutting computation, and makes the network tolerant of small shifts.

Numbers to quote: a 28×28 image into 64 dense neurons is 50,240 parameters. 64 conv filters of 3×3 is 640.

C3

3×3 kernel on a 5×5 input, stride 2

F2024a Q6c-ii

The window moves 2 cells at a time and must stay inside the 5×5 grid. Where can its top-left corner sit?

Show the answer

How it's convolved: put the 3×3 kernel on the top-left corner of the input. Multiply the 9 input values under it by the 9 kernel weights, add them up (plus the bias), and write that one number into the output. Move 2 columns right and repeat. At the end of a row, go back to the left edge and move 2 rows down. With input depth 1, each patch is a single 3×3 slice.

Where the corner can sit: columns 0 and 2, and rows 0 and 2. Column 4 doesn't work, because the window would need columns 4, 5 and 6, and the input ends at column 4.

patches per side = ⌊(5 − 3) / 2⌋ + 1 = 2
patches = 2 × 2 = 4 → output feature map is 2×2

Trap

With stride 1 it's (5 − 3 + 1)² = 9 patches and a 3×3 output. The patches overlap in both cases: here the middle row and column are shared.

What convolution is: slide the kernel over the input. At each position, multiply the overlapping values cell by cell and add them up. The grid of results is the feature map.

What pooling is: replace each window of the feature map with one summary value. Max pooling keeps the largest. A 2×2 window over this 2×2 map covers everything, so the answer is 35. If ReLU is applied first, −30 becomes 0, and the max is still 35.

Flip or not?

CNNs (Keras, PyTorch) slide the kernel without flipping it, which is what's above. The maths definition of convolution flips the kernel 180° first, giving [[1, −0.5], [−1, 1]], a feature map of [[10, 15], [25, −40]], and a max pool of 25. C5

The purpose of max pooling

F2024a Q5e

Max pooling throws away 3 out of every 4 numbers. Why would you want that?

Show the answer
  • Downsampling: a 2×2 pool with stride 2 keeps ¼ of the values. Later layers have less to compute and fewer parameters to learn, which also reduces overfitting.
  • Keeps the strongest signal: the max says whether the feature is present in that region, not exactly where. Small shifts in the image barely change the output.
  • A wider view: after pooling, the next 3×3 conv window covers a bigger part of the original image. That's how the spatial hierarchy is built.
  • No parameters: pooling learns nothing. It's a fixed operation.

Example: 4×4 feature map, 2×2 max pool, stride 2. Each coloured block becomes its largest value.

1321 4652 3110 1224
→
6534

16 values become 4, and each block's strongest response survives.

"State the number of neurons" is your choice. 4 per hidden layer is about half of the 8 flattened inputs. With 8 and 8 instead, the dense part is 72 + 72 + 27 and the total is 186. Use the formula and any sensible choice earns the marks.

(ii) Activations: ReLU after each conv layer and in both hidden dense layers. Softmax at the output, because there are 3 classes. Pooling and flatten have no activation. Loss: categorical cross-entropy.

Traps

Conv 2's input depth is 1 (Conv 1 had one filter), so each of its kernels is 2×2×1, not 2×2×2. "Same" with stride 1 keeps 4×4. Pooling and flatten add 0 parameters. Every filter has one bias.

Doomsday · 6 lines

If you remember nothing else

  1. Convolution: slide the kernel, multiply-and-add each patch, and the results form a feature map. CNN libraries don't flip the kernel.
  2. Size: output side = ⌊(n − k) / s⌋ + 1 for valid; same padding gives ⌈n / s⌉. Patches = output height × width.
  3. Parameters: conv (k·k·input depth + 1) × filters; pooling and flatten 0; dense (inputs + 1) × neurons.
  4. Max pooling keeps the biggest value in each window: it downsamples, keeps the strongest signal, tolerates small shifts and widens the next layer's view. It has no parameters.
  5. CNN beats dense: local patterns with shared weights give translation invariance, a spatial hierarchy, and far fewer parameters.
  6. Activations: ReLU in conv and hidden dense layers; softmax at a multiclass output (sigmoid for binary).

Concepts follow F. Chollet, Deep Learning with Python, chapter on convnets. Every number on this page was recomputed in Python.
