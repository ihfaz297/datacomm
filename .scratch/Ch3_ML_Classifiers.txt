▪When classes are not linearly separable,

▪Logistic regression is a far better default: it

data.
▪Despite the name, logistic regression is a 
classification model, not a regression model.

THE LOGISTIC MODEL
From Probability to a Binary Decision
▪The sigmoid's output is directly interpreted as a class probability —
e.g. P(y=1|x;w) = 0.8.
▪A quantizer converts that probability into a binary outcome using a 0.5 threshold.
▪Equivalently, the decision only depends on the sign of the net input z.
▪Many real applications — such as weather forecasting — care about the probability 
itself, not just the hard label.

REGULARIZATION
L2 Regularization & Weight Decay
▪The most common form is L2 regularization (L2 shrinkage or weight decay).
▪λ is the regularization parameter; increasing it strengthens regularization.
▪We add the L2 term to the cost function, which shrinks the weights — equivalent to 
placing a zero-mean Gaussian prior over them.
▪Since the derivative of w² is 2w, gradient descent naturally decays each weight in 
proportion to its size.

MAXIMUM MARGIN
Maximum-Margin Classification
▪SVM's optimization objective is to maximize the margin.
▪The margin is the distance between the separating hyperplane and the closest 
training samples — the support vectors.
▪Intuitively, a larger margin means lower generalization error.
▪Models trained with a small margin are prone to overfitting.

=== PAGE BREAK ===
22 / 35
M A X I M U M  M A R G I N
The Mathematics of the Margin
▪The positive and negative hyperplanes run parallel to the decision boundary, offset 
by ±1 in the net-input scale.
▪The distance between these two planes — the margin — works out to 2 / ‖w‖.
▪‖w‖ is the Euclidean length (norm) of the weight vector.
w₀ + wᵀxpos = 1        w₀ + wᵀxneg = −1

THE KERNEL TRICK
The Kernel Trick: General Blueprint
1
Transform training data into a higher-dimensional space via a mapping 
function φ(·).
2
Train a linear SVM to classify the data in that new feature space.
3
Apply the same mapping φ(·) to transform new, unseen data.
4
Classify unseen data using the linear SVM model.
Problem: constructing φ explicitly is computationally expensive for high dimensions.

THE KERNEL TRICK
Avoiding the Explicit Mapping
▪The decision boundary only ever needs the dot product of two feature vectors —
never the vectors' individual coordinates in the new space.
▪So, we define a kernel function that computes φ(x)ᵀφ(z) directly, without ever 
materializing φ.
▪Worked example: squaring the dot product ⟨x·z⟩implicitly computes the dot product 
of a 3-D feature mapping — with none of the expansion cost.

The Radial Basis Function kernel is the most widely used kernel in practice.

variance, to build a more robust, better-generalizing model.

Repeat k

Build k trees this way,

Aggregate all trees'

Sampling with replacement:
In random sampling with replacement, we 
always return the selected number to the 
urn so that the probability of drawing a 
particular number at each turn does not 
change; we can draw the same number 
more than once. In other words, in 
sampling with replacement, the samples 
(numbers) are independent and have a 
covariance of zero.
Sampling without replacement:
In sampling without replacement, we do 
not put the number back into the urn 
after each turn. Consequently, the 
probability of drawing a particular 
number from the set of remaining 
numbers in the next round depends on 
the previous round.

WRAPPING UP
Hyperparameters and key takeaways
Parameters that matter
k — number of trees
More trees generally improve performance, at 
higher computational cost.
n — bootstrap sample size
Usually set equal to the training set size; smaller n 
increases tree diversity (and variance).
d — features per split
A common default is √m, where m is the total 
number of features.
Takeaways
Single decision trees are interpretable but 
prone to overfitting without pruning.

The curse of dimensionality
The curse of dimensionality describes the phenomenon 
where the feature space becomes increasingly sparse for 
an increasing number of dimensions of a fixed-size 
training dataset. KNN is very susceptible to overfitting due 
to the curse of dimensionality. We can think of even the 
closest neighbors as being too far away in a high
dimensional space to give a good estimate.
