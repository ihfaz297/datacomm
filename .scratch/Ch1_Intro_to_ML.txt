What is Machine Learning? 
• Machine learning is the application and science of algorithms that make 
sense of data.
• Machine learning is the field of study that gives computers the ability to 
learn without being explicitly programmed” —Arthur L. Samuel, AI pioneer, 
1959
• “A computer program is said to learn from experience E with respect to 
some class of tasks T and performance measure P, if its performance at 
tasks in T, as measured by P, improves with experience E.” —Tom Mitchell, 
Professor at Carnegie Mellon University

Making predictions with supervised learning
• Learn a model from labeled 
training data that allows us to 
make predictions about unseen 
or future data.
• For the email spam filtering 
example , we can train a model 
using a supervised ML algorithm 
on a corpus of labeled emails, 
which are correctly marked as 
spam or non-spam, to predict 
whether a new email belongs to 
either of the two categories.

=== PAGE BREAK ===
Classification for predicting class labels
• Supervised learning task with discrete class 
labels, such as in the previous email spam 
filtering example, is also called a 
classification task.
• A binary classification task given 30 training 
examples; 15 training examples are labeled 
as the negative class (minus signs) and 15 
training examples are labeled as the positive 
class (plus signs).
• A supervised ML algorithm learns a rule—
the decision boundary (dashed line)

=== PAGE BREAK ===
Multiclass classification
• A typical example of a multiclass classification task is handwritten 
character recognition.
• Also, Digits recognition between 0 and 9, is a multiclass classification 

=== PAGE BREAK ===
Regression for predicting continuous outcome
• Supervised learning where the 
outcome signal is a continuous value 
is regression
• We are given a number of predictor 
(explanatory) variables and a 
continuous response variable 
(outcome), and we try to find a 
relationship between those variables 
that allows us to predict an 
outcome.

=== PAGE BREAK ===
Solving interactive problems with
reinforcement learning
• In reinforcement learning, the goal is 
to develop a system (agent) that 
improves its performance based on 
interactions with the environment.
• Learns a series of actions that 
maximizes a so-called reward via an 
exploratory trial-and-error approach

=== PAGE BREAK ===
Discovering hidden structures with
unsupervised learning
• In unsupervised learning deals with unlabeled data or data of 
unknown structure
• Explore the structure of data to extract meaningful information 
without the guidance of a known outcome variable

Finding subgroups with clustering
• Clustering is an exploratory data analysis 
technique that allows us to organize a pile 
of information into meaningful 
subgroups (clusters) without having any 
prior knowledge of their group 
memberships
• Example, three distinct groups based on 
the similarity of their features, x1 and x2

=== PAGE BREAK ===
Basic terminology in ML
• Training example: A row in a table representing the dataset and 
synonymous with an observation, instance, or sample.
• Training: Model fitting, for parametric models similar to parameter 
estimation.
• Feature, abbrev. x: A column in a data table or data (design) matrix. 
Synonymous with variable, input, attribute, or covariate.
• Target, abbrev. y: Synonymous with outcome, output, response 
variable, dependent variable, (class) label, and ground truth.
• Loss function: Often used synonymously with a cost function or an 
error function.

=== PAGE BREAK ===
A roadmap for building machine learning systems
• Preprocessing – getting data into shape
• Transforming the features in the range [0, 1] or a standard normal distribution 
with zero mean and unit variance
• Training and selecting a predictive model
• Compare at least a handful of different algorithms in order to train and select 
the best performing model. 
• Evaluating models and predicting unseen data instances
• After selecting a model that has been fitted on the training dataset, we can 
use the test dataset to estimate how well it performs on this unseen data
